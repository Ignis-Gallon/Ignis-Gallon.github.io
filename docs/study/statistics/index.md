# 통계와 데이터 분석

2024년 1월부터 8월 사이에 데이터 분석을 하면서 필요한 통계 개념을 강의, 블로그, 논문을 보고 정리한 노트입니다. 기술 통계와 가설검정 같은 기초에서 시작해 비모수 검정과 회귀 모델, 시계열 분석과 이상치 탐색, 클러스터링으로 이어집니다.

**통계 기초**

- [통계학 기본](01-statistics-basics.md): 가설 설정, 변수와 척도, 기술 통계와 추리 통계, 정규분포와 Z-score, 중심극한정리, 귀무가설과 대립가설
- [각종 통계 정리](02-statistics-summary.md): 표본 평균의 분포와 중심극한정리의 세 가정, 정규성 검정을 하는 이유
- [데이터 분석 공부](03-data-analysis-study.md): 중심극한정리의 정확한 정의와 흔한 오해, 시계열 이상 탐지의 접근 방법과 이상의 유형
- [논문통계분석 기초](04-thesis-statistics-basics.md): 유의확률과 유의수준, t-검정, 분산분석, 카이제곱 검정, 상관관계분석, 회귀분석
- [중심극한정리와 중심화 경향](05-central-limit-theorem-and-central-tendency.md): 중심극한정리의 성립 조건과 적용이 어려울 때의 대안, 평균값·중앙값·최빈값
- [박스 플롯](06-box-plot.md): 상자그림을 이루는 값과 IQR의 1.5배를 쓰는 이상치 기준

**검정과 회귀 모델**

- [독립표본/대응표본의 비모수 검정](07-nonparametric-tests.md): 비모수 통계를 쓰는 조건, 윌콕슨 순위합, 크루스칼 왈리스, 윌콕슨 부호순위, 프리드먼 검정
- [카이제곱 검정](08-chi-square-test.md): 한 대상이 빈도 1만큼만 기여해야 한다는 독립성 조건
- [검정력, 1종 오류와 2종 오류](09-power-type1-type2-errors.md): 두 오류의 정의와 관계, 검정력을 고려한 연구 대상 수 산출
- [GLMM](10-glmm.md): 확률 분포, 선형 회귀, 로지스틱 회귀, 최대우도법에서 고정 효과와 무작위 효과, 모델 진단과 결과 해석까지
- [Count Data Model](11-count-data-model.md): 종속변수가 횟수일 때 쓰는 푸아송 회귀와 음이항 회귀, 모델 선택 기준

**시계열과 이상치**

- [시계열 분석에 대한 조사 및 공부](12-time-series-analysis-survey.md): 시계열 상관분석 방법(피어슨, 켄달, TLCC, DTW), 정상성, 자기공분산, 관련 논문 분석
- [이상치 탐색을 위한 통계적 방법과 활용 방안](13-statistical-outlier-detection.md): 이상치의 개념과 분류, 단변량·시계열 자료의 탐색 방법과 장단점, 정규성 검정 방법

**클러스터링**

- [클러스터링 기초 공부](14-clustering-basics.md): 계층적 방식과 분할적 방식, k-mean과 Mean-shift 클러스터링의 과정과 장단점
- [DSBA 클러스터링](15-dsba-clustering.md): 군집화의 원칙과 타당성 평가 지표(Dunn Index, Silhouette), K-Means의 한계, DBSCAN, Mean-Shift
