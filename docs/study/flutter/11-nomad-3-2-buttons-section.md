# 3.2 Buttons Section

작성일 2023-02-28 · 최종 수정일 2023-03-04
{ .post-date }

- 재사용가능한 Widget을 만들어본다.
- CrossAxisAlignment는 해당 Column 혹은 Row에서 수평 정렬을 어떻게 맞출 것인지를 담당한다.
- MainAxisAlignment는 해당 Column 혹은 Row에서 수직 정렬을 어떻게 맞출 것인지를 담당한다.
- SizedBox를 이용해서 Widget 간의 공간을 설정할 수 있다.
- Container : 컨테이너는 div같은 것이며, child를 가지고 있는 단순한 box이다.  
    (HTML의 div)
- Container 안에 Text를 넣어주고, decoration 옵션을 줘서 디자인해준다.
- 특정 Widget에 Padding을 주려면 Padding Widget으로 감싼 다음, 그 안에 넣어주자.
