# 선형대수 (MML 2장)

"Mathematics for Machine Learning"(Deisenroth, Faisal, Ong) 2장 Linear Algebra를 읽으며 정리한 노트입니다. 책의 절 순서를 따라 세 편으로 나누었고, 예제는 직접 따라 풀며 적었습니다.

- [2.1 ~ 2.3: 연립선형방정식과 행렬](01-linear-systems-and-matrices.md): 연립선형방정식의 해와 기하학적 의미, 역행렬과 전치, 특수해와 일반해, Gaussian Elimination
- [2.4 ~ 2.6: 벡터 공간, 선형 독립, 기저와 랭크](02-vector-spaces-and-basis.md): group에서 vector space와 subspace까지의 정의, 선형 독립의 판정, basis와 차원, rank의 성질
- [2.7 ~ 2.8: 선형 사상과 아핀 공간](03-linear-mappings-and-affine-spaces.md): 선형 사상의 행렬 표현, 기저 변환, image와 kernel, rank-nullity theorem, affine subspace와 affine mapping

책은 <https://mml-book.github.io/>에서 볼 수 있습니다.
