# 람다 함수와 고차 함수

작성일 2022-09-28 · 최종 수정일 2022-12-19
{ .post-date }

## `람다 함수`

- `람다 함수`

    람다 함수는 코틀린과 다른 많은 프로그래밍 언어에서 제공하는 `익명 함수`의 정의 기법이다.  
    람다 함수를 간단하게 정의할 때 이용하며, 람다식이라고도 한다. 코틀린에서는 `고차 함수`를 지원하기 때문에 `람다 함수`를 자주 사용하게 된다.

    `고차 함수`는 `매개변수`나 `반환값`으로 함수를 이용하는데, `람다 함수`는 주고받을 함수를 간단하게 정의할 때 사용한다. 즉, 람다 함수는 그 자체도 가치가 있지만, `고차 함수`를 이해하고 사용하려면 꼭 알아야 한다.

- `람다 함수 선언과 호출`

```kotlin
{ 매개변수 -> 함수 본문 }
```

- 코틀린에서 `람다 함수`를 사용하는 `규칙`은 다음과 같다.

    1. 람다 함수는 `{ }`로 표현한다.
    2. `{ }` 안에 화살표 ( `→` ) 가 있으며 화살표 왼쪽은 `매개변수`, 오른쪽은 `함수 본문` 이다.
    3. 함수의 `반환 값`은 함수 본문의 `마지막 표현식`이다.

```kotlin
// 람다 함수의 선언
val sum = { no1: Int, no2: Int -> no1 + no2 }

// 람다 함수의 호출
sum(10, 20)

// 람다 함수 선언과 호출
{no1: Int, no2: Int -> no1 + no2} (10, 20)
```

- `매개변수가 없는 람다 함수`

```kotlin
{ -> println("function call") }

// 화살표를 생략한 람다 함수
{ println("function call") }
```

- 함수에 매개변수가 항상 있어야 하는 것은 아니다. 람다 함수에서 화살표 왼쪽이 매개변수를 정의하는 부분인데, 매개변수가 없을 경우 비워 두면 된다. 그런데, 위의 스니펫처럼 람다 함수에 매개 변수가 없을 경우 화살표까지 생략해도 된다.

- `매개 변수가 1개인 람다 함수`

```kotlin
// 1)
fun main() {
	val some = {no: Int -> println(no)}
	some(10)
}

// 2)
fun main() {
	val some: (Int) -> Unit = {println(it)}
	some(10)
}
```

- 2) : 람다 함수 앞에 (Int) → Unit 이 매개변수가 1개인 람다 함수임을 알려준다. 이처럼 함수의 매개변수가 1개일 때는 중괄호 안에서 매개변수 선언을 생략하고 println(it) 처럼 it 키워드로 매개변수를 이용할 수 있다.

람다 함수에서 it을 이용해 매개변수를 사용하는 것은 해당 매개변수의 타입을 식별할 수 있을때만 가능하다.

- `람다 함수의 반환`

    람다 함수도 함수이므로 자신을 호출한 곳에 결괏값을 반환해야 할 때가 있다. 그런데 람다 함수에서는 `return문`을 사용할 수 없다.

    람다 함수의 반환값은 본문에서 마지막 줄의 `실행 결과`이다.

    ```kotlin
    fun main() {
    	val some = {no1: Int, no2: Int ->
    			println("in lambda function")
    			no1 * no2
    		}

    	println("result : ${some(10,20)")
    }

    // some(10, 20)의 결과로 람다 함수의 마지막 줄인 no1 * no2, 즉, 200이 return 된다.
    ```

- `함수 타입과 고차 함수`

```kotlin
val some: (Int, Int) -> = { no1: Int, no2: Int -> no1 + no2 }
```

- 람다 함수에서 함수의 타입은 (Int, Int)
