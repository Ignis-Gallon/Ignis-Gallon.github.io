- % vs vh

    - 100% : container(parent) 크기의 100%
    - 100vh : 부모에 상관없이 보이는 화면에 대해서 크기 지정

```css
body, html {
	height: 100%;
}
```

⇒ body의 부모는 html이므로, 크기를 화면 전체로 하려면 둘다 100%로 지정해 주어야 한다.
