# CSS

2023년 7월에 CSS 레이아웃을 공부하며 정리한 노트입니다. Flex는 블로그 글과 유튜브 영상을 보고 적었고, 드림코딩 묶음은 [드림코딩의 프론트엔드 입문 강의](https://www.youtube.com/watch?v=gGebK7lWnCk&list=PLv2d7VI9OotQ1F92Jp9Ce7ovHEsuRQB3Y&index=7)를 들으며 적은 기록입니다. display 값의 차이와 반응형 웹(media query, container query)을 찾아보며 쓴 글도 함께 묶었습니다.

**Flex**

- [Flex 1](01-flex-1.md): Container와 Items에 적용하는 속성의 구분, flex와 inline-flex의 차이, 주축과 교차축, 정렬 속성, flex 단축 속성
- [Flex 2](02-flex-2.md): main axis와 cross axis, flex-direction, justify-content, align-items, flex-wrap과 align-content, gap
- [Flex 3](03-flex-3.md): flex-direction의 row, column과 reverse 값, flex-wrap의 nowrap과 wrap

**display**

- [display block, inline, inline-block](04-display-block-inline-inline-block.md): 한 줄 전체를 차지하는 block, 콘텐츠 너비만 차지하는 inline, 나란히 놓이면서 크기 조절이 되는 inline-block

**드림코딩 CSS**

- [드림코딩 CSS 1: selector](05-dreamcoding-css-1-selector.md): cascading 방식과 Author, User, Browser 스타일의 적용 순서, 선택자 종류
- [드림코딩 CSS 3: flexBox](06-dreamcoding-css-3-flexbox.md): Container 속성과 Item 속성, 축 개념, 100%와 100vh의 차이
- [드림코딩 CSS 4: responsive web design](07-dreamcoding-css-4-responsive-web-design.md): 유동적인 레이아웃, 기기별 화면 너비 구분, media query의 mode와 min-width, max-width
- [드림코딩 CSS 5: Responsive Web Example](08-dreamcoding-css-5-responsive-web-example.md): 반응형 헤더 예제, 레이아웃 구조 먼저 파악하기, semantic tag, 아이콘과 폰트 준비
- [드림코딩 CSS 6: EM & REM](09-dreamcoding-css-6-em-rem.md): 절대 단위와 상대 단위, em과 rem의 기준 차이, vw와 vh, 단위를 고르는 기준
- [드림코딩 CSS 7: grid](10-dreamcoding-css-7-grid.md): grid-template 계열 속성과 grid-gap, grid-column-start, grid-area 등 셀 속성
