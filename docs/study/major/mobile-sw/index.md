# 모바일SW

4학년 1학기에 수강한 과목의 수업 노트입니다. Tizen .NET 환경에서 Xamarin.Forms(XAML)로 화면을 만들고 C#으로 제어하는 방법을 다룬 과목으로, 오프라인 수업의 레이아웃 실습과 온라인 C# 강의 내용을 주차별로 정리했고, 학기 말 워치 앱 프로젝트를 구상한 메모를 함께 두었습니다.

- [1주차: Tizen 개요, .NET 플랫폼](01-week-01-tizen-dotnet.md): 수업 개요, Tizen의 개요와 애플리케이션 유형, C#의 특징, .NET 플랫폼, 라이브러리와 프레임워크의 차이
- [2주차: 개발 환경과 에뮬레이터 설치](02-week-02-dev-environment.md): Visual Studio 2019, .NET SDK, Java SDK와 환경변수, Tizen SDK와 에뮬레이터 설치, 문제 해결
- [4주차: XAML 기본 구조와 StackLayout 실습](03-week-04-xaml-stacklayout.md): MainPage.xaml의 구조, StackLayout과 AbsoluteLayout 실습, XAML과 C# 코드의 매칭
- [5주차: StackLayout 주요 속성, .NET 플랫폼](04-week-05-stacklayout-properties.md): Orientation과 Spacing, 두 방향 Options 실습, .NET 플랫폼과 C#으로 할 수 있는 일
- [6주차: Layout Options, C# 클래스와 namespace](05-week-06-layout-options.md): Layout과 Label에 주는 정렬 옵션의 차이, VerticalOptions 적용 여부에 따른 변화, using static, Class, namespace
- [7주차: Nested Layout, Fill과 Expand 옵션](06-week-07-nested-layout.md): 중첩된 Layout에서 옵션이 영역에 미치는 영향, Fill, Expand, FillAndExpand의 차이
- [9주차: 리소스 추가, 액자형 UI](07-week-09-resources-frame-ui.md): 이미지 리소스 추가, WidthRequest와 HeightRequest, AbsoluteLayout의 좌표 지정, 절차지향과 객체지향
- [10주차: C# 문법, 프로젝트 계획](08-week-10-csharp-project-plan.md): 워치 페이스 프로젝트 계획, Object 형식과 박싱·언박싱, Equals, this() 생성자, static, 상속, 열거형, Nullable, 배열과 컬렉션, Try/Catch
- [11주차: Property, Interface](09-week-11-property-interface.md): public 필드의 문제와 Property, 자동 구현 Property, Initializer, Interface의 Property
- [12주차: View 요소 추가, 비동기, Easing](10-week-12-view-async-easing.md): C# 코드로 Layout에 View 요소 추가하기, 비동기 메서드, 타이머, Easing, Task.WhenAny, Button과 탭 제스처
- [프로젝트: 워치 앱 화면 구상](11-project-watch-app.md): 프로젝트를 위해 모은 참고 자료, 워치 이미지 배치 방법, Watch Page와 Instant Alarm Page 구상
