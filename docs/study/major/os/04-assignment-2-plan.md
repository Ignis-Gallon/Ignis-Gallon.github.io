# Plan: 스레드 기반 콘솔 게임 구현 계획

- [x] 먼저 Window 앱을 열어서 게임을 동작시키도록 만들기.

게임을 구상하고 게임 동작에 필요한 함수들과 규칙들을 구현하여 게임이 동작하도록 만든다.

- [x] 만들어진 게임을 바탕으로 Thread화 하기

각 함수를 Thread를 바탕으로 동작시켜서 동시에 돌아갈 수 있도록 만들기.

- [x] 사용자의 키보드 입력을 받아 개별적으로 이동하기(스레드화)

- [ ] 사용자 입력 lock 필요한지 판단해보기

- [ ] 난이도에 딱 맞는 속도 설정(공의 속도는 난이도마다 차이 없음. bar가 움직이는 속도 차이)

- [ ] 랠리마다 공 속도 상승하는 정도 설정

- [ ] 점수 글자로 표시하기

- [ ] Main으로 돌아가는거 확인하기 → TerminateThread (안되면 없애기)

- [ ] 공 각도 설정

이 과정에서 공유변수를 활용하기 위해 적당히 lock 처리 해야 함.

- Stage는 총 두 개. Main에서는 난이도를 설정하고 시작할 수 있음.

    - Press ‘F1’ To Change The Level
    - Press ‘Space’ To Start  The Game

예를 들어, 유저의 키보드 입력을 체크하는 함수가 있다면 그 함수를 Thread화 시키고,  
Thread 내에서 무한루프를 돌려서 계속해서 개별적으로 체크할 수 있도록 한다.

즉, 렌더링과 입력 체크를 별개의 스레드로 동작시킨다.

그리고 충돌을 체크하는 함수가 있어야 한다. 이 함수는 결국 각 Thread가 공유하는 전역변수를 체크해서  
현재 유저의 바와 컴퓨터의 바, 그리고 현재 공의 위치를 체크해서 충돌을 체크해야 한다.

이것은 공유 변수를 사용하므로 결국 lock을 사용해야할 것으로 생각되는데, lock을 하면 사용자의 위치와  
컴퓨터의 위치, 그리고 공의 위치가 한 번에 하나씩 밖에 들어가지 못하므로 결국 동기적으로 체크하는 것과  
차이가 없을 수 있다.

그리고 랠리가 계속되거나 한 번 승리하게 되면 공의 속도가 더욱 빨라지고, 유저의 바의 속도는 일정하지만  
컴퓨터 바의 속도는 점점 빨라져야 한다.
