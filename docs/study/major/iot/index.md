# 사물인터넷

3학년 2학기에 수강한 사물인터넷 수업의 노트입니다. 과목 이름은 사물인터넷이지만 네트워크 프로토콜을 중심으로 다룬 과목으로, 네트워크의 기본 구성 요소에서 시작해 TCP의 혼잡 제어, BGP와 Stable Path Problem, P2P와 Chord, 암호화, Multicasting과 Ad-Hoc 네트워크 라우팅까지 다룹니다.

- [1주차 - Basic Network Components](01-week-01-basic-network-components.md): 패킷 교환과 회선 교환, 네 가지 패킷 지연과 Throughput, OSI 계층 구조, ARP·Reverse ARP·DHCP
- [2주차 - Subnetting, GBN & Selective Repeat](02-week-02-subnetting-gbn-selective-repeat.md): 서브넷 마스크와 Longest Prefix Matching, TCP와 UDP 비교, Go-Back-N과 Selective Repeat의 동작
- [3주차 - Congestion Control](03-week-03-congestion-control.md): 혼잡의 원인과 큐잉 정책, Fair Queueing, AIMD, MTU와 MSS, Slow Start, Fast Retransmit, Fast Recovery
- [4주차 - Congestion Avoidance](04-week-04-congestion-avoidance.md): 혼잡 비트를 실어 보내는 DECbit, Lock-out 문제와 Early Random Drop, RED의 세부 동작과 예제
- [4주차 - Border Gateway Protocol](05-week-04-border-gateway-protocol.md): Autonomous System, Interdomain·Intradomain 라우팅의 차이, BGP-4와 정책 충돌, Stable Path Problem
- [5주차 - Dispute Digraph](06-week-05-dispute-digraph.md): Conflict Arc와 Transmission Arc로 Cycle 유무 확인하기, Dynamic Execution, 경로 선택 정책
- [6주차 - P2P & Chord System](07-week-06-p2p-chord-system.md): 중앙 서버 방식과 분산 방식의 탐색 비용, Chord의 핑거 테이블 탐색 예제, 링에 참여하는 세 단계
- [7주차 - Symmetric Key(DES) & RSA](08-week-07-symmetric-key-des-rsa.md): 대칭키 방식의 장단점, DES의 키 길이와 16단계 라운드 구조, 공개키 시스템과 RSA
- [12주차: Shared Tree, Ad-Hoc 라우팅](09-week-12-shared-tree-ad-hoc-routing.md): Shared Tree와 Shortest-Path Tree, Proactive·Reactive 프로토콜, Source Routing과 Destination Routing, MANET
- [Multicasting](10-multicasting.md): Forwarding Tree의 종류, Learning Bridge, RPF·RPB·TRPB·RPM, NMR Reporting 예제, Link-State 멀티캐스트 라우팅, 도메인 간 멀티캐스팅
