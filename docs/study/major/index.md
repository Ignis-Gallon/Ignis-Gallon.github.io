# 전공

학부 전공 수업을 들으며 과목별로 정리한 노트입니다. 수업 시간에 적은 내용을 거의 그대로 옮겼습니다.

**2학년 2학기**

- [알고리즘](algorithms/index.md): 자료구조와 정렬, 그래프 탐색, Greedy, 동적 계획법, 최단 경로, Backtracking
- [마이크로컨트롤러응용](microcontroller/index.md): AVR의 포트 제어, 인터럽트, UART, ADC, Timer
- [오픈소스SW설계](open-source-sw/index.md): Linux 명령과 Shell Script, 빌드 도구, Git, 시스템 콜, 프로세스, 시그널, 쓰레드
- [객체기반SW설계](oop-cpp/index.md): C++의 클래스, 상속과 다형성, 파일 입출력, template, STL

**3학년 1학기**

- [센서공학](sensor-engineering/index.md): 센서의 원리, GPS와 LIDAR, ROS, 자율주행의 위치 추정과 차선 인식
- [임베디드구조](embedded-architecture/index.md): CPU와 명령어, 제어장치, 파이프라인, 기억장치
- [운영체제](os/index.md): 프로세스와 스케줄링, 동기화, Deadlock, 메모리 관리, Assembly
- [임베디드비젼시스템](embedded-vision/index.md): 엔트로피와 부호화, 무손실·손실 압축, 양자화, JPEG

**3학년 2학기**

- [사물인터넷](iot/index.md): 혼잡 제어, BGP, P2P, 암호화, 멀티캐스트와 Ad-Hoc 라우팅
- [네트워크구조및설계](network/index.md): Application에서 Link Layer까지의 계층별 프로토콜, TCP, Socket Programming
- [영상처리](image-processing/index.md): 점 처리와 이웃 처리, Fourier Transform, 복원, 분할, 컬러 처리
- [데이터베이스](database/index.md): ER 모델, 관계형 모델과 관계 대수, SQL, 정규화
- [인공지능](ai/index.md): Agent와 탐색, 지식 표현과 추론, 신경망, 머신러닝
- [임베디드시스템특강](embedded-special-topics/index.md): 머신러닝과 딥러닝의 기초, 신경망 학습, 최적화, CNN
