# 임베디드구조

3학년 1학기에 수강한 과목으로, 컴퓨터 구조를 다룹니다. 하드웨어 구성 요소와 버스, 시동 과정, CPU의 연산장치·레지스터·제어장치, 명령어 사이클과 파이프라인, 기억장치, 인터럽트, 병렬처리 시스템 구조를 주차별로 정리한 노트입니다.

- [1주차: 하드웨어 구성 요소, 마이크로컴퓨터 구조, 운영체제 역할](01-week-01.md): CPU·기억장치·입출력장치와 Bus, 칩셋, PCI-E, 메인보드, 운영체제와 컴퓨터 언어, 소스 코드에서 프로그램을 만드는 과정
- [2주차: CPU 스케줄링, 시동 과정, 신호선, CPU 프로세서](02-week-02.md): 시뮬레이션과 에뮬레이션, 다중작업과 멀티스레드, BIOS와 UEFI, ISA, 버퍼와 Tri-state, 보조프로세서, 레지스터
- [3주차: 연산장치, CPU 명령어](03-week-03.md): 마이크로 연산과 레지스터 전송 언어(RTL), ALU, 명령어 형식과 주소지정 방식, 정수와 부동소수점 표현
- [4주차: Languages and Strings, Finite State Machine](04-week-04.md): 알파벳·문자열·빈 문자열 ε·Kleene Star, 문자열 길이와 Concatenation, DFSM과 NDFSM
- [5주차: 논리연산 응용, 제어장치, 명령어 사이클](05-week-05.md): AND·XOR 응용과 시프트 연산, 하드와이어와 마이크로프로그램 제어방식, 명령어 인출·실행 사이클, 실습
- [6주차: 병렬처리, 명령어 파이프라인](06-week-06.md): CALL과 RETURN의 마이크로연산, 인터럽트의 의미와 처리 흐름, 병렬계산의 유형과 속도 상승, 2단계 파이프라인
- [7주차: 슈퍼스칼라, 기억장치, 메모리 계층](07-week-07.md): 2단계·4단계 파이프라인과 슈퍼 파이프라인, 슈퍼스칼라 구조, 엔디언, 메모리 계층 구조와 가상 메모리
- [14주차: 인터럽트, 고성능 컴퓨팅 시스템 구조](08-week-14.md): 버스와 I/O 자원의 충돌, IRQ 공유와 버스 마스터링, 버스 사이클, 인터럽트 제어 방식, Flynn의 분류
