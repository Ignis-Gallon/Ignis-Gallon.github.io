# Server

2023년 2월부터 2024년 1월까지 진행한 서버와 데이터베이스 프로젝트의 기록입니다. 온도 모니터링 서비스의 서버를 Node.js로 옮기고 기능을 추가했으며, 이후 운영 DB의 오래된 데이터를 백업하는 작업을 맡았습니다.

**Node.js and Web**

- [Spring → Node.js 서버 전환](01-spring-to-nodejs.md): 기기 등록·정보 수정 화면과 API를 새 서버로 옮긴 과정
- [측정 데이터 달력·그래프 조회](02-calendar-graph.md): 화면 스크립트 분석과 개선, 그래프가 깨지는 날짜의 원인, 차트 라이브러리 비교
- [토큰 기반 인증](03-token-auth.md): 액세스 토큰 발급, 검증 미들웨어, 만료 시 화면이 넘어가지 않던 문제
- [가스 센서 모니터링 화면](04-gas-sensor-monitoring.md): 센서별 그래프 네 개의 구성과, 확대·회전 뒤에도 유지되는 레이아웃
- [관리자 페이지](05-admin-page.md): 계정 관리 화면과 대시보드, 바뀐 항목만으로 수정 쿼리 만들기
