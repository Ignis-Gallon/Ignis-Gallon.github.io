- Using the Navigator

Router : Flutter에서 Route는 스마트폰에서 보여지는 하나의 페이지라고 볼 수 있다. Navigator는 모든 Routes, 페이지를 관리하며, Stack이라는 자료구조 형식으로 Route의 객체들을 관리한다. Stack을 관리하기 위해 push와 pop이라는 메서드를 사용한다.

Flutter에서 앱 페이지의 관리는 Navigator가 담당하고, 이를 관리하기 위해 Stack 자료구조를 사용한다. 그렇기 때문에 만약 한 페이지 상에서 다른 페이지를 띄우게 된다면, 첫 번째 페이지를 제거하고 다시 그리는 것이 아니라 첫 번째 페이지 위에 두 번째 페이지를 다시 그리는 것이다.

onPressed: Navigator.push(context, route)

이와 같이 Button에 onPressed로 달아줄 수 있는데, 여기서 context를 전달하는 이유는 다음과 같다.

context가 가지고 있는 Widget tree의 위치 정보에 근거해서 현재 화면상에 보여지는 페이지가 어떤 페이지인지 확인하고, 이 페이지 위에 push 함수가 이동하길 원하는 새로운 Route를 쌓아올려야 하기 때문이다. 즉, 첫 번째 페이지 위에 두 번째 페이지를 쌓아 올리기 위해서는 첫 번째 페이지의 위치를 확실히 알아야하기 때문이다.

이 때, route에는 MaterialPageRoute()를 만들어주어야 하는데, required argument로 builder:를 사용해야 한다. MaterialPageRoute()를 만들고 builder를 만들며 context를 할당받아야 하는 것은 일종의 안전장치라고 볼 수 있다.

```dart
onPressed: () {
  Navigator.push(
    context,
    MaterialPageRoute(builder: (BuildContext context) {
      return const MedicineCreationScreen();
    }),
  );
},
```

```dart
onPressed: () {
  Navigator.push(
    context,
    MaterialPageRoute(
      builder: (context) => const MedicineCreationScreen(),
    ),
  );
},
```

이와 같이 코드를 구성할 수 있을 것이다.

안드로이드는 기본적으로 새로운 창이 만들어질 때 아래에서 위로 올라오는 애니메이션을 가지고 있으며, iOS는 기본적으로 좌, 우로 움직이는 애니메이션을 가지고 있다.
