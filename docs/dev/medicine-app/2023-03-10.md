- 데이터 저장 (SharedPreferences, Local Storage)을 통해 어플을 다시 켤 때 데이터 저장되도록 만들기.

SharedPreferences : 적은 양의 데이터를 저장하려면 이를 SharedPreferences를 사용할 수 있다. 일반적으로 이 곳에는 유저가 다음 작업을 진행할 때 더 적은 양의 일을 진행하도록 돕기 위한 정보들을 저장한다. 주로 설정 정보 등을 저장한다. 만약 적은 양의 정보가 아니라 많은 양의 정보를 저장하고 싶다면, database를 사용하는 것이 좋다. 

플러터에서는 SQFlite를 통해서 데이터베이스를 쉽게 사용할 수 있다. database helper class를 이용하면 데이터 베이스 관리를 쉽게 할 수 있으며, 업데이트나 코드 유지보수에도 용이하다. 이 때 database helper class는 singleton class이기 때문에 사용이 간편하다. 

(SQflite 를 이용한 Local Storage 구현 중)

Local Data를 initState()에서 가져오려고 했는데, 이는 Future를 반환하기 때문에 initState()에서 호출할 수 없다고 한다. 이를 해결하는 방법에 대해서 찾아본다.

[Flutter - How to run Async ’await’ Code in initState()](https://www.fluttercampus.com/guide/63/how-to-run-async-await-code-in-initstate-flutter-app/)

initState를 직접적으로 async function으로 만들고, await을 호출할 수 없기 때문에 따로 async function을 만들고 이를 호출하는 방식으로 대체한다.

현재 직면한 문제는 데이터를 처리하는 방식이 잘못됐다는 것이다. 데이터를 DB에 저장할 수는 있는데, 이를 받아오고 그릴 때 형식이 달라서 그리지 못하고 있다. 전면적으로 고쳐야 할 것으로 보인다.
