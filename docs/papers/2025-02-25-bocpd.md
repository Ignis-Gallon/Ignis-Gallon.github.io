# Bayesian Online Changepoint Detection: run length의 posterior를 재귀적으로 갱신하기

"Bayesian Online Changepoint Detection"(Adams and MacKay, 2007)은 change point detection(CPD)을 공부할 때 가장 먼저 만나는 논문이다. 줄여서 BOCPD라고 부른다. 인턴으로 있던 연구실의 선행 연구인 [DTF-net](2024-12-29-dtf-net.md)도 이 방법을 비교 대상으로 삼는다. CPD에 대한 배경 지식이 없어 DTF-net의 관련 연구 부분이 이해되지 않았기 때문에, 이 논문을 중심으로 CPD를 공부했다.

처음에는 논문만 읽었는데 식 하나하나에서 막혔다. 그래서 논문의 전개를 풀어 쓴 Gregory Gundersen의 블로그 글 "Bayesian Online Changepoint Detection"을 함께 읽으며 처음부터 다시 정리했다. 이 글은 두 자료를 읽은 기록을 합친 것이다.

| 시기 | 읽은 방식 |
|---|---|
| 2025-02-24 | 베이즈 정리를 복습하고 논문의 큰 틀을 잡았다 |
| 2025-02-25 | 논문의 도입부와 2절을 읽으며 용어마다 질문을 적었다 |
| 2025-02-26 ~ 02-27 | 재귀식의 유도, 초기 조건, 지수족 부분의 질문을 하나씩 풀었다 |
| 2025-03-06 ~ 03-07 | 블로그 글을 따라 모델, 재귀식, 알고리즘을 처음부터 다시 정리했다 |

글의 앞부분은 논문의 내용이고, 중간중간 읽으면서 생긴 질문과 찾은 답을 함께 적었다. 표기는 논문을 따랐고, 블로그의 용어는 처음 나올 때 함께 적었다. 켤레 사전분포와 지수족은 [베이즈 이론 스터디](../study/bayesian/index.md)에 따로 정리했다.

## 한눈에 보기

- 시계열이 change point를 경계로 여러 구간(partition)으로 나뉘고, 구간마다 다른 parameter의 분포에서 데이터가 나온다고 가정한다.
- 마지막 change point 이후 지난 시간인 run length $r_t$를 잠재 변수로 둔다.
- 매 시점마다 run length의 posterior $P(r_t \mid x_{1:t})$를 계산한다. 이 계산은 이전 시점의 결과를 넘겨받아 갱신하는 재귀식으로 이루어진다.
- 재귀식의 재료는 세 가지다. change point가 일어날 사전 확률(hazard function), 새 데이터의 predictive 확률, 이전 시점의 결과다.
- 켤레 관계에 있는 지수족 모델을 쓰면 predictive 확률을 충분통계량의 덧셈만으로 갱신할 수 있다.

## 배경: 베이즈 정리

BOCPD는 베이즈 정리를 이용해 change point가 일어났을 확률을 계속 갱신한다. 그래서 베이즈 정리부터 다시 정리했다.

$$
P(\theta \mid x) = \frac{P(x \mid \theta)\,P(\theta)}{P(x)}
$$

| 항 | 이름 | 뜻 |
|---|---|---|
| $P(\theta)$ | prior | 데이터를 보기 전에 가지고 있던 믿음 |
| $P(x \mid \theta)$ | likelihood | $\theta$가 주어졌을 때 데이터 $x$가 관찰될 확률 |
| $P(\theta \mid x)$ | posterior | 데이터를 관찰한 뒤 갱신된 믿음 |
| $P(x)$ | evidence | 데이터 $x$가 나올 전체 확률 |

베이즈 정리를 이해하기 어려웠던 이유는 확률을 보는 관점이 달라서였다. 빈도주의에서 "동전의 앞면이 나올 확률이 50%"는 100번 던지면 50번쯤 앞면이 나온다는 뜻이다. 베이즈 관점에서는 확률을 주장에 대한 신뢰도로 해석한다. 베이즈 정리는 불확실한 주장에 대한 신뢰도를 새로운 근거로 갱신하는 규칙이다.

갱신이 반복된다는 점이 중요하다. 발병률이 0.1%인 질병이 있고, 검사의 민감도가 99%, 특이도가 98%라고 하자.

- 양성 판정을 한 번 받은 사람이 실제로 병에 걸렸을 확률은 약 4.7%다. 검사가 정확해도 병에 걸린 사람 자체가 드물기 때문이다.
- 같은 사람이 두 번째 검사에서도 양성이 나왔다면, 앞에서 구한 확률(반올림하기 전의 값 약 4.72%)을 새로운 prior로 놓고 다시 계산한다. 결과는 약 71.0%다.

새로운 근거는 백지 상태에서 믿음을 정하는 것이 아니라 이전의 믿음을 갱신한다. posterior가 다음 단계의 prior가 된다. BOCPD가 매 시점 하는 일이 이것이다.

prior와 posterior가 같은 분포 계열에 속할 때 그 prior를 conjugate prior라고 한다. 이 경우 posterior를 닫힌 형태로 얻을 수 있어 수치 적분이 필요 없다. 정규분포의 평균에는 정규분포, 포아송 분포에는 감마 분포, 이항분포에는 베타 분포가 conjugate prior다. 이 성질이 7절에서 쓰인다.

## 1. 문제 설정

### Changepoint

논문에서 changepoint는 순차 데이터의 generative parameter가 급격히 변하는 지점이다. Generative parameter는 데이터를 생성하는 확률 모델의 parameter다. 관측된 데이터가 어떤 확률적 과정에서 만들어졌다고 가정할 때, 그 과정을 결정하는 변수들이다. Change point detection은 이 parameter가 언제 변하는지를 모델링하고 추론하는 일이다.

### 기존 연구와의 차이

- **빈도주의 접근**: Page, Lorden의 연구부터 support vector machine을 쓰는 방법까지, online으로 change point를 탐지하는 방법들이 있었다.
- **Bayesian 접근**: 대부분 offline이고 후향적(retrospective)이었다. 전체 데이터에 접근할 수 있어야 하고, 데이터를 가장 잘 설명하는 구간 분할(segmentation)을 찾거나 change point 위치의 posterior에서 표본을 뽑는 기법에 집중했다. 실시간 탐지는 할 수 없었다.

이 논문은 Bayesian 방식으로 online 탐지를 한다. 지금까지 관측한 데이터만으로 다음 데이터의 분포를 만들어 내는 것이 목표다(causal predictive filtering). 전체 시퀀스를 되돌아보며 나누는 대신, 가장 최근의 change point가 언제였는지에 집중한다.

### Product partition model

논문은 $T$개의 관측값이 서로 겹치지 않는 구간(product partition)으로 나뉜다고 가정한다.

- 구간과 구간 사이의 경계가 change point다. Change point 전후의 데이터는 서로 다른 확률 모델에서 생성된 것으로 본다.
- 구간 $\rho$ 안의 데이터는 분포 $P(x_t \mid \eta_\rho)$에서 i.i.d.로 뽑힌다. $\eta_\rho$가 그 구간의 generative parameter다.
- parameter $\eta_\rho$들도 i.i.d.다. 구간마다 parameter를 새로 뽑는 상위 분포가 따로 있다고 보는 것이다. Change point가 일어나면 다음 구간의 parameter가 새로 정해지고, 이전 구간의 parameter와는 독립이다.

parameter까지 상위 분포에서 뽑는다고 두는 이유도 정리했다. 구간들이 완전히 따로라면 구간이 늘어날 때마다 새 분포를 처음부터 추정해야 하고, 데이터가 적은 구간에서는 믿을 만한 추정이 어렵다. 같은 상위 분포에서 나왔다고 두면 새 구간에서도 그 상위 분포를 prior로 쓸 수 있다. 계층적 모델을 쓰는 Bayesian 추론과 잘 맞는 구조다.

## 2. Run length

BOCPD가 직접 추정하는 것은 change point의 위치가 아니라 run length다.

- **Run length $r_t$**: 마지막 change point 이후 지금까지 지난 시간. 같은 분포에서 연속으로 생성된 데이터의 개수다.
- **$x_t^{(r)}$**: run length가 $r_t$일 때 현재 구간에 속하는 관측값의 집합. 블로그에서는 $\mathbf{x}^{(\ell)}$로 쓴다.
- **$x_{a:b}$**: 시점 $a$부터 $b$까지의 관측값.

run length는 한 시점에 두 가지로만 움직인다.

$$
r_t =
\begin{cases}
0 & \text{시점 } t\text{에서 change point가 일어난 경우} \\
r_{t-1} + 1 & \text{그렇지 않은 경우}
\end{cases}
$$

시간에 따라 그리면 run length는 1씩 올라가다가 change point에서 0으로 떨어지는 톱니 모양이 된다.

### Run length는 왜 불확실한가

신호가 깨끗하다면 change point가 눈에 보이고 run length도 바로 알 수 있다. 그러나 실제 데이터에는 노이즈가 있어서 마지막 change point가 정확히 언제였는지 알 수 없다. 관측한 데이터로 추론할 수 있을 뿐이다. 현재 시점의 run length는 3일 수도 있고 10일 수도 있다.

그래서 BOCPD는 run length를 하나의 값으로 정하지 않고, 가능한 모든 run length에 대한 확률 분포를 유지한다. "마지막 변화가 언제였는가"에 대한 여러 가설에 확률을 부여해 두고, 데이터를 관찰할 때마다 그 확률을 갱신하는 것이다. $r_t$는 이산 변수이므로 이 분포는 확률 질량 함수다. 시점 $t$에서 가능한 run length는 0부터 $t$까지다.

### $P_{\text{gap}}$과 run length

논문에는 $P_{\text{gap}}(g)$도 나온다. change point 사이의 간격 $g$가 따르는 이산 확률 분포로, 각 구간의 길이가 어떤 분포를 따르는지를 나타낸다.

처음에는 이것이 run length와 무엇이 다른지 알 수 없었다. 둘 다 길이이고 둘 다 이산이다. 정리한 답은 다음과 같다.

- run length는 "지금까지 이 구간이 얼마나 이어졌는가"다. 매 시점 값이 달라지고, 데이터로 추정해야 하는 대상이다.
- $P_{\text{gap}}$은 "구간은 보통 얼마나 길게 이어지는가"다. change point가 얼마나 자주 일어나는지에 대한 사전 지식이다.

$P_{\text{gap}}$이 주어지면 run length가 어떻게 움직일지를 예측할 수 있다. change point가 자주 일어나는 분포라면 run length가 짧은 값을 가질 확률이 높다. 현재 진행 중인 구간의 길이는 다음 change point가 올 때까지 정해지지 않는다는 점도 둘의 차이다.

## 3. 구하려는 두 분포

BOCPD가 계산하는 것은 두 가지다.

**다음 데이터의 predictive 분포.** 지금까지의 데이터로 다음 데이터가 따를 분포를 예측한다.

$$
P(x_{t+1} \mid x_{1:t}) = \sum_{r_t} P(x_{t+1} \mid r_t, x_t^{(r)})\,P(r_t \mid x_{1:t})
$$

**Run length의 posterior.** 지금까지의 데이터가 주어졌을 때 run length가 $r_t$일 확률이다.

$$
P(r_t \mid x_{1:t}) = \frac{P(r_t, x_{1:t})}{P(x_{1:t})}
$$

첫 번째 식의 구조는 일반적인 Bayesian 예측과 같다. 데이터 $\mathcal{D}$와 parameter $\theta$가 있을 때 새 데이터 $\hat{x}$의 posterior predictive는 모델의 예측을 parameter의 posterior로 가중해 적분한 것이다.

$$
p(\hat{x} \mid \mathcal{D}) = \int p(\hat{x} \mid \theta)\,p(\theta \mid \mathcal{D})\,d\theta
$$

parameter가 실제로 무엇인지 모르므로 그것도 확률 변수로 두고, 가능한 모든 값에 대해 주변화(marginalization)하는 것이다. BOCPD에서는 주변화하는 대상이 run length다. $r_t$가 이산 변수이므로 적분이 아니라 합이 된다.

- $P(x_{t+1} \mid r_t, x_t^{(r)})$: run length가 $r_t$라고 가정했을 때, 현재 구간의 데이터만으로 계산한 다음 데이터의 분포다. 논문은 marginal predictive, 블로그는 UPM(underlying probabilistic model) predictive라고 부른다.
- $P(r_t \mid x_{1:t})$: 그 가정이 얼마나 그럴듯한지에 대한 가중치다. 블로그는 RL posterior라고 부른다.

예를 들어 $t = 5$라면 가능한 run length 각각에 대해 "run length가 이 값이라면 현재 구간은 여기부터이고, 그 구간의 데이터로 보면 다음 값은 이런 분포를 따른다"를 계산한다. 그리고 각 분포를 그 run length의 posterior 확률로 가중해 더한다. 결과는 run length에 대한 불확실성을 반영한, 평균적인 다음 데이터의 분포다.

결국 $r_t$는 change point의 발생을 모델링하기 위한 수단이다. 가능한 모든 run length에 대해 주변화한다는 것은, 현재 시점에서 change point가 일어난 경우와 일어나지 않은 모든 경우를 함께 고려하겠다는 뜻이다.

### 질문: 왜 posterior는 $x_{1:t}$ 전체를 보고, predictive는 $x_t^{(r)}$만 보는가

predictive가 현재 구간의 데이터만 쓰는 것은 모델의 가정에서 나온다. change point 이전의 데이터는 현재 구간과 독립이므로, 마지막 change point 이후의 데이터만이 현재 구간의 모델을 결정한다.

반면 run length의 posterior는 전체 데이터를 조건으로 둔다. "현재 구간이 어디서 시작했는가"를 판단하려면 현재 구간의 데이터만으로는 부족하고, 그 이전 데이터와 비교해야 하기 때문이다. 이 posterior는 한 번에 계산하는 것이 아니라 이전 시점의 결과에 새 데이터를 반영해 재귀적으로 갱신하므로, 결과적으로 과거 전체의 정보가 누적되어 들어간다.

### 질문: 주변화한 뒤에는 왜 $x_t^{(r)}$가 식에서 사라지는가

좌변 $P(x_{t+1} \mid x_{1:t})$에는 $x_t^{(r)}$가 없다. 이유는 $x_t^{(r)}$가 새로운 정보가 아니기 때문이다. $r_t$가 정해지면 $x_{1:t}$ 가운데 어떤 데이터가 현재 구간에 속하는지도 자동으로 정해진다. 그래서 $r_t$에 대해 합을 취하고 나면 조건에는 $x_{1:t}$만 남는다. 당시에는 이 설명에 확신이 없어 다시 확인할 것으로 표시해 두었다.

### 질문: 구간 안의 데이터가 i.i.d.인데, 왜 다음 데이터가 과거 데이터에 의존하는가

공부하는 동안 여러 번 되돌아온 질문이다. 구간 안의 데이터가 서로 독립이라면 $x_{t+1}$은 $x_t^{(r)}$와 무관해야 할 것 같은데, 식에는 $x_t^{(r)}$가 조건으로 들어가 있다.

답은 "독립"이 parameter가 주어졌을 때의 독립이라는 데 있다. posterior predictive의 식을 다시 보면 알 수 있다.

$$
f(\tilde{x} \mid x) = \int f(\tilde{x} \mid \theta, x)\,f(\theta \mid x)\,d\theta = \int f(\tilde{x} \mid \theta)\,f(\theta \mid x)\,d\theta
$$

$\theta$를 알면 $\tilde{x}$는 과거 데이터 $x$와 독립이다. 두 번째 등호가 그 뜻이다. 그러나 우리는 $\theta$를 모른다. 과거 데이터는 $\theta$의 posterior $f(\theta \mid x)$를 통해 예측에 들어온다. 즉 과거 데이터가 다음 데이터를 직접 결정하는 것이 아니라, 구간의 parameter가 무엇인지에 대한 믿음을 갱신하고, 그 믿음이 다음 데이터의 분포를 정한다.

## 4. 재귀식

run length의 posterior를 구하려면 joint 확률 $P(r_t, x_{1:t})$를 구한 뒤 evidence로 정규화하면 된다. evidence는 joint를 모든 run length에 대해 더한 것이다.

$$
P(r_t \mid x_{1:t}) = \frac{P(r_t, x_{1:t})}{\sum_{r_t'} P(r_t', x_{1:t})}
$$

핵심은 joint 확률을 재귀적으로 구하는 것이다. 논문의 식 (3)이다.

$$
\begin{aligned}
P(r_t, x_{1:t}) &= \sum_{r_{t-1}} P(r_t, r_{t-1}, x_{1:t}) \\
&= \sum_{r_{t-1}} P(r_t, x_t \mid r_{t-1}, x_{1:t-1})\,P(r_{t-1}, x_{1:t-1}) \\
&= \sum_{r_{t-1}} P(r_t \mid r_{t-1})\,P(x_t \mid r_{t-1}, x_t^{(r)})\,P(r_{t-1}, x_{1:t-1})
\end{aligned}
$$

### 유도를 한 줄씩

이 세 줄을 이해하는 데 가장 많은 시간을 썼다. 줄마다 쓰인 규칙을 따로 적으면 다음과 같다.

**첫째 줄: 전체 확률의 법칙.** 원래 식에는 $r_{t-1}$이 없다. 이를 넣되 모든 값에 대해 더해서 주변화한다.

$$
P(A) = \sum_{B} P(A, B)
$$

이 법칙은 서로 의존하는 변수에만 쓸 수 있는 것이 아니다. 어떤 중간 변수로든 확률을 풀어 쓸 수 있는 일반적인 규칙이다. 다만 가능한 $B$를 빠짐없이 고려해야 한다.

**둘째 줄: 곱셈 법칙.** $A = \{r_t, x_t\}$를 새로 들어온 부분, $B = \{r_{t-1}, x_{1:t-1}\}$을 이전까지의 부분으로 놓고 $P(A, B) = P(A \mid B)\,P(B)$를 적용한다. 처음에는 이 분해가 왜 가능한지 근거를 찾지 못했는데, 변수를 이렇게 두 묶음으로 나누어 보니 곱셈 법칙 그대로였다.

- $P(r_{t-1}, x_{1:t-1})$: 이전 시점의 run length와 그때까지의 모든 데이터에 대한 joint 확률
- $P(r_t, x_t \mid r_{t-1}, x_{1:t-1})$: 과거가 주어졌을 때 현재의 run length와 데이터가 나올 확률

**셋째 줄: 조건부 곱셈 법칙과 두 가지 가정.** 앞의 항에 $P(A, B \mid C) = P(A \mid C)\,P(B \mid A, C)$를 한 번 더 적용한다.

$$
P(r_t, x_t \mid r_{t-1}, x_{1:t-1}) = P(r_t \mid r_{t-1}, x_{1:t-1})\,P(x_t \mid r_t, r_{t-1}, x_{1:t-1})
$$

여기에 모델의 가정 두 가지가 들어간다.

1. **Run length는 직전 run length에만 의존한다.**

    $$
    P(r_t \mid r_{t-1}, x_{1:t-1}) = P(r_t \mid r_{t-1})
    $$

    $r_{t-1}$을 알면 $r_t$의 가능성은 0이거나 $r_{t-1} + 1$, 둘뿐이다. 과거 데이터 전체를 몰라도 change point가 일어났는지 여부만 알면 된다.

2. **데이터는 현재 구간의 데이터에만 의존한다.**

    $$
    P(x_t \mid r_t, r_{t-1}, x_{1:t-1}) = P(x_t \mid r_{t-1}, x_t^{(r)})
    $$

    조건으로 주어진 것은 $x_{1:t-1}$ 전체지만, run length를 알면 그중 현재 구간에 속하는 데이터만 골라낼 수 있고, 예측에 필요한 것은 그 데이터뿐이다.

### 세 개의 재료

결과적으로 joint 확률은 세 항의 곱을 이전 run length에 대해 더한 것이다.

| 항 | 이름 | 역할 |
|---|---|---|
| $P(r_t \mid r_{t-1})$ | changepoint prior | change point가 일어날 사전 확률. hazard function으로 정한다 |
| $P(x_t \mid r_{t-1}, x_t^{(r)})$ | predictive 확률 | 이전 run length마다, 새 데이터가 그 구간에서 나올 확률 |
| $P(r_{t-1}, x_{1:t-1})$ | message | 이전 시점에 계산해 둔 joint 확률 |

이전 시점의 joint 확률을 기억해 두었다가 현재 시점의 계산에 가져다 쓰기 때문에 재귀가 된다. 이전 시점의 확률 분포가 다음 시점으로 전달되면서 hazard와 predictive 확률이 곱해져 갱신되는 구조라서 message-passing 알고리즘이라고 부른다. 현재 상태의 분포를 과거 상태의 분포로부터 구한다는 점에서 hidden Markov model의 forward 알고리즘과 닮은 동적 계획법이다.

### 질문: Markov 성질은 왜 성립하는가

run length가 직전 값에만 의존한다는 가정이 왜 통하는지 궁금했다. 정리한 답은 "그렇게 모델링했기 때문"이다. run length는 정의상 0으로 떨어지거나 1 늘어나는 것밖에 할 수 없으므로, $r_{t-1}$이 그 이전의 정보를 모두 담고 있다. 간격의 분포를 기하분포로 골라서 이 성질이 생기는 것이 아니다. 기하분포를 골라서 얻는 것은 5절의 memoryless hazard다.

### 질문: 논문과 블로그의 식이 다르다

마지막 줄의 predictive 항이 두 자료에서 다르게 적혀 있다.

- 논문: $P(x_t \mid r_{t-1}, x_t^{(r)})$. $r_t$가 사라지고 $r_{t-1}$이 남는다.
- 블로그: $p(x_t \mid r_t, \mathbf{x}^{(\ell)})$. $r_{t-1}$이 사라지고 $r_t$가 남는다.

당시에는 어느 쪽이 맞는지 정하지 못하고, "모델의 가정에 따라 이렇게 정리되며 이 항이 predictive라는 것만 알면 된다"고 넘어갔다. 9절의 알고리즘을 보면 $x_t$의 predictive는 이전 시점에서 넘겨받은 parameter, 즉 $r_{t-1}$에 대응하는 구간의 parameter로 계산한다. 이 점에서는 $r_{t-1}$을 남긴 논문의 표기가 알고리즘과 맞는다.

$r_t$가 조건에서 빠지는 이유는 다음과 같이 이해했다. 새 관측값 $x_t$가 어떤 분포에서 왔는지를 정하는 것은 현재 구간에 어떤 데이터가 들어 있는가이지, 구간의 길이를 나타내는 숫자가 아니다. 어떤 데이터가 현재 구간에 속하는지를 확인한 뒤라면, 길이 정보는 predictive의 계산에 더 기여하지 않는다.

## 5. Changepoint prior: hazard function

$P(r_t \mid r_{t-1})$은 hazard function $H$로 정한다.

$$
P(r_t \mid r_{t-1}) =
\begin{cases}
H(r_{t-1} + 1) & r_t = 0 \\
1 - H(r_{t-1} + 1) & r_t = r_{t-1} + 1 \\
0 & \text{그 밖의 경우}
\end{cases}
$$

Hazard function은 간격의 분포 $P_{\text{gap}}$으로 정의한다.

$$
H(\tau) = \frac{P_{\text{gap}}(g = \tau)}{\sum_{t=\tau}^{\infty} P_{\text{gap}}(g = t)}
$$

- 분자는 간격이 정확히 $\tau$일 확률이다.
- 분모는 간격이 $\tau$ 이상일 확률이다. 지금까지 change point가 없었다면 change point는 $\tau$, $\tau + 1$, $\tau + 2$, $\dots$ 가운데 어딘가에서 일어나므로, 그 모든 경우의 확률을 더한 것이다. 이 분모를 survival function이라고 한다.

처음에는 "어떤 시점에 일어날 확률을 그 시점 이후 전체에 일어날 확률로 나눈 값"이 왜 change point의 발생 확률이 되는지 와닿지 않았다. 조건부 확률로 읽으면 풀린다. $H(\tau)$는 "$\tau$ 전까지 change point가 없었다는 조건 아래에서, 바로 $\tau$에서 change point가 일어날 확률"이다.

$$
H(\tau) = P(\text{간격이 } \tau \mid \text{간격이 } \tau \text{ 이상})
$$

### 기하분포일 때 hazard가 상수가 되는 이유

논문은 $P_{\text{gap}}$이 timescale $\lambda$의 이산 지수분포(기하분포)이면 과정이 memoryless가 되고 hazard가 상수 $H(\tau) = 1/\lambda$가 된다고 말한다. 직접 계산해 보았다. 매 시점 change point가 일어날 확률을 $p$라고 하면 간격의 분포는 다음과 같다.

$$
P_{\text{gap}}(g) = (1 - p)^{g-1}p
$$

분모는 무한 등비급수의 합이다.

$$
\sum_{t=\tau}^{\infty} (1 - p)^{t-1}p = (1 - p)^{\tau - 1}
$$

따라서 hazard는 $\tau$와 무관한 상수가 된다.

$$
H(\tau) = \frac{(1 - p)^{\tau - 1}p}{(1 - p)^{\tau - 1}} = p
$$

기하분포의 평균이 $1/p$이므로, 평균 간격을 $\lambda$로 두면 $p = 1/\lambda$이고 $H(\tau) = 1/\lambda$다.

Memoryless는 마지막 change point가 얼마나 오래전이었든 지금 change point가 일어날 확률은 같다는 뜻이다. 이전에 change point가 없었다는 사실이 앞으로의 확률에 영향을 주지 않는다. 처음에는 이것이 구간 안의 데이터가 i.i.d.라는 가정에서 나오는 것인지 헷갈렸는데, 그와는 관계가 없다. 간격의 분포를 기하분포로 골랐기 때문에 생기는 성질이다.

## 6. Growth 확률과 changepoint 확률

run length가 두 가지로만 움직이므로 joint 확률의 계산도 두 가지로 나뉜다.

- **Growth 확률** ($r_t = r_{t-1} + 1$): run length가 이어지는 경우다. $r_t = 3$이라면 $r_{t-1}$은 반드시 2여야 한다. 이전 run length가 하나로 정해져 있으므로 합이 필요 없고 항 하나만 계산하면 된다.
- **Changepoint 확률** ($r_t = 0$): run length가 0으로 떨어지는 경우다. 이전 run length가 무엇이었든 change point는 일어날 수 있다. 그래서 가능한 모든 $r_{t-1}$에 대해 더해야 한다.

가로축을 시간, 세로축을 run length로 놓고 그리면 격자 모양의 그림이 된다. 각 시점의 각 run length가 점 하나이고, 점마다 위쪽 대각선으로 올라가는 선(growth)과 바닥으로 떨어지는 선(changepoint)이 하나씩 나간다. 시점 $t$의 점 가운데 바닥에 있는 점 하나만 이전 시점의 모든 점에서 선을 받고, 나머지 점은 바로 아래 대각선의 점 하나에서만 선을 받는다.

이 구조 때문에 이전 시점의 message를 모두 기억해 두어야 한다. $t = 6$의 계산에는 $t = 5$에서 가능했던 run length 6개 각각의 joint 확률이 필요하다.

## 7. Predictive 확률의 계산: conjugate-exponential model

남은 것은 predictive 확률을 어떻게 계산하느냐다. 원래는 구간의 parameter $\eta$에 대해 적분해야 한다.

$$
P(x_{t+1} \mid r_t, x_t^{(r)}) = \int P(x_{t+1} \mid \eta)\,P(\eta \mid r_t, x_t^{(r)})\,d\eta
$$

매 시점, 모든 run length에 대해 이 적분을 하는 것은 부담이 크다. 논문은 지수족(exponential family) likelihood와 그에 대한 conjugate prior를 쓰면 이 계산이 간단해진다는 점을 이용한다.

지수족 likelihood는 다음 형태다.

$$
p(x \mid \eta) = h(x)\,g(\eta)\exp\{\eta^\top u(x)\}
$$

$\eta$는 natural parameter, $u(x)$는 충분통계량(sufficient statistic)이다. 이에 대한 conjugate prior는 hyperparameter $\chi$, $\nu$로 쓸 수 있다.

$$
p(\eta \mid \chi, \nu) = f(\chi, \nu)\,g(\eta)^{\nu}\exp\{\eta^\top \chi\}
$$

데이터 $X = \{x_1, \dots, x_N\}$을 관측한 뒤의 posterior는 likelihood와 prior의 곱이다. $\eta$와 무관한 항을 빼고 정리하면 다음과 같다.

$$
p(\eta \mid X, \chi, \nu) \propto g(\eta)^{N + \nu}\exp\left\{\eta^\top\left(\sum_{n=1}^{N} u(x_n) + \chi\right)\right\}
$$

prior와 같은 형태이고 hyperparameter만 바뀌었다.

$$
\nu' = \nu_{\text{prior}} + N, \qquad \chi' = \chi_{\text{prior}} + \sum_{n=1}^{N} u(x_n)
$$

즉 posterior를 구하는 일이 "관측 개수를 세고 충분통계량을 더하는 일"로 바뀐다. predictive도 이 두 hyperparameter만 있으면 닫힌 형태로 계산된다. $\eta$에 대한 적분을 매번 새로 할 필요가 없다.

### Run length마다 따로 유지한다

BOCPD에서는 run length마다 현재 구간에 속한 데이터가 다르므로 hyperparameter도 run length마다 따로 가진다. 시점 $t$, run length $\ell$의 hyperparameter는 다음과 같이 갱신한다.

$$
\begin{aligned}
\nu_t^{(0)} &= \nu_{\text{prior}}, & \chi_t^{(0)} &= \chi_{\text{prior}} \\
\nu_t^{(\ell)} &= \nu_{t-1}^{(\ell-1)} + 1, & \chi_t^{(\ell)} &= \chi_{t-1}^{(\ell-1)} + u(x_t)
\end{aligned}
$$

- change point가 일어난 경우($\ell = 0$)에는 새 구간이 시작되므로 prior의 값으로 돌아간다.
- 구간이 이어진 경우에는 이전 시점에 한 칸 짧은 run length가 가지고 있던 값에 새 데이터의 충분통계량을 더한다.

$t = 0, 1, 2$를 손으로 따라가 보면 run length마다 서로 다른 hyperparameter가 생기는 것이 보인다. $t = 2$에서 $\ell = 2$의 값은 $x_1$과 $x_2$가 모두 더해진 것이고, $\ell = 1$의 값은 $x_2$만 더해진 것이고, $\ell = 0$의 값은 prior 그대로다. 그래서 시점마다 모든 run length의 hyperparameter를 유지해야 한다. 다만 직전 시점의 것만 있으면 되므로 메모리 부담은 크지 않다.

정리하면 joint 확률의 세 재료가 모두 싸게 얻어진다. changepoint prior는 hazard function에서, 이전 시점의 joint는 message로, predictive는 충분통계량으로 계산된다.

## 8. 초기 조건

재귀식이므로 시작점 $P(r_0)$가 필요하다. 두 가지 경우를 생각한다.

**첫 데이터 직전에 change point가 일어났다고 보는 경우.** 가장 간단한 조건이다. 관측을 새로 시작하는 상황에 해당하고, 모든 확률을 run length 0에 준다.

$$
P(r_0 = 0) = 1
$$

**이미 진행 중인 과정을 중간부터 관측하는 경우.** 데이터를 이전부터 보아 오다가 중간 시점부터 BOCPD를 적용하는 상황이다. 현재 구간이 이미 얼마나 이어져 왔는지를 모르므로, 초기 run length를 분포로 둔다.

$$
P(r_0 = \tau) = \frac{1}{Z}S(\tau), \qquad S(\tau) = \sum_{t=\tau+1}^{\infty} P_{\text{gap}}(g = t)
$$

$S(\tau)$는 survival function으로, change point 없이 구간이 $\tau$보다 길게 이어질 확률이다. $Z$는 확률의 합을 1로 맞추는 정규화 상수다. 과거에 change point가 자주 일어났다면 큰 $\tau$의 확률이 작아지고, 드물었다면 커진다.

이론적으로 $\tau$는 무한대까지 가능하지만, 실제로는 관측된 시점의 수 이하로 제한하거나 확률이 무시할 만큼 작아지는 곳에서 자른다.

## 9. 알고리즘

지금까지의 내용을 순서대로 놓으면 논문의 알고리즘이 된다.

1. **초기화.** $P(r_0)$를 8절의 두 방식 중 하나로 정하고, $\nu_1^{(0)} = \nu_{\text{prior}}$, $\chi_1^{(0)} = \chi_{\text{prior}}$로 둔다.

2. **새 데이터 $x_t$를 관측한다.**

3. **Predictive 확률을 계산한다.** 이전 시점에 가능했던 run length 각각에 대해, 그 run length가 넘겨준 hyperparameter로 $x_t$의 확률을 구한다.

    $$
    \pi_t^{(r)} = P(x_t \mid \nu_t^{(r)}, \chi_t^{(r)})
    $$

4. **Growth 확률을 계산한다.** change point가 아닌 경우이므로 $1 - H$를 곱한다.

    $$
    P(r_t = r_{t-1} + 1, x_{1:t}) = P(r_{t-1}, x_{1:t-1})\,\pi_t^{(r)}\,(1 - H(r_{t-1}))
    $$

5. **Changepoint 확률을 계산한다.** 모든 이전 run length에 대해 더한다.

    $$
    P(r_t = 0, x_{1:t}) = \sum_{r_{t-1}} P(r_{t-1}, x_{1:t-1})\,\pi_t^{(r)}\,H(r_{t-1})
    $$

6. **Evidence를 계산한다.**

    $$
    P(x_{1:t}) = \sum_{r_t} P(r_t, x_{1:t})
    $$

7. **Run length의 posterior를 구한다.**

    $$
    P(r_t \mid x_{1:t}) = \frac{P(r_t, x_{1:t})}{P(x_{1:t})}
    $$

8. **충분통계량을 갱신한다.**

    $$
    \nu_{t+1}^{(r+1)} = \nu_t^{(r)} + 1, \qquad \chi_{t+1}^{(r+1)} = \chi_t^{(r)} + u(x_t)
    $$

9. **다음 데이터를 예측한다.**

    $$
    P(x_{t+1} \mid x_{1:t}) = \sum_{r_t} P(x_{t+1} \mid x_t^{(r)}, r_t)\,P(r_t \mid x_{1:t})
    $$

10. **2단계로 돌아간다.**

5단계에서 주의할 점이 있다. $\pi_t^{(r)}$는 이전 run length마다 다른 값이고 합 안에 들어 있다. change point가 일어나면 hyperparameter가 prior로 돌아가지만, 그것은 다음 시점부터 쓰일 $\nu^{(0)}$, $\chi^{(0)}$의 이야기다. $x_t$ 자체의 확률은 직전까지 이어지던 구간의 hyperparameter로 계산한다. hazard의 인자는 논문의 표기를 그대로 옮겼다. 5절의 식과 인자가 하나 다르지만, hazard가 상수이면 값은 같다.

전체를 한 문장으로 줄이면 이렇다. 현재 시점에서 가능한 모든 run length를 고려하고, 각 run length마다 그것으로 이어질 수 있는 이전 run length를 모두 고려해 확률을 갱신한 뒤, 그 불확실성을 반영해 다음 데이터를 예측한다.

## 10. 결과를 읽는 법

BOCPD의 출력은 시점마다의 run length posterior다. 가로축을 시간, 세로축을 run length로 놓고 각 칸의 확률을 진하기로 표시하면, 확률이 높은 run length가 대각선을 따라 올라가다가 어느 시점에서 0으로 떨어지는 모양이 나타난다. 각 시점에서 확률이 가장 높은 run length를 따라갈 때 그 값이 0으로 떨어지는 곳이 change point가 일어났을 가능성이 가장 높은 지점이다.

두 가지를 알게 되었다.

- BOCPD는 change point의 위치를 확정해서 내놓지 않는다. 매 시점 run length에 대한 확률 분포를 내놓을 뿐이다.
- 다음 데이터의 predictive 분포는 알고리즘의 한 단계로 계산되기는 하지만, change point를 읽는 데 직접 쓰이는 것은 run length의 posterior다. 처음에는 predictive 분포를 구하는 것이 근본적인 목적이고 run length posterior는 그 과정에서 나오는 것이라고 이해했는데, change point 탐지의 관점에서는 run length posterior 쪽이 더 중요하다고 생각을 바꾸었다.

## 11. 두 predictive는 같은 것인가

알고리즘에는 predictive가 두 번 나온다. 3단계에서 joint 확률을 갱신할 때 한 번, 9단계에서 다음 데이터를 예측할 때 한 번이다. 3단계의 것은 충분통계량으로 계산한다는 것을 이해했는데, 9단계의 것은 어떻게 구하는지가 한동안 풀리지 않았다.

정리한 결론은 둘이 같은 계산이고 시점만 다르다는 것이다.

| | joint 확률 안의 predictive | 예측에 쓰는 predictive |
|---|---|---|
| 목적 | $x_t$의 확률을 구해 run length posterior를 갱신한다 | $x_{t+1}$의 분포를 예측한다 |
| 쓰는 충분통계량 | 이전 시점까지의 것 | 현재 시점까지 갱신한 것 |
| 식 | $P(x_t \mid r_{t-1}, x_t^{(r)})$ | $P(x_{t+1} \mid r_t, x_t^{(r)})$ |
| Gaussian 예 | $\mathcal{N}(x_t \mid \mu_{t-1}, \sigma^2 + \sigma_{t-1}^2)$ | $\mathcal{N}(x_{t+1} \mid \mu_t, \sigma^2 + \sigma_t^2)$ |

8단계에서 갱신한 hyperparameter로 9단계의 predictive를 만들고, 그 분포에 다음 시점의 실제 관측값을 넣은 것이 다음 반복의 3단계다. 그래서 시점 $t$에서 예측을 위해 만든 predictive를 시점 $t + 1$의 joint 계산에 그대로 쓸 수 있다. 재귀적으로 가져다 쓴다는 것이 핵심이다. 당시에는 이 결론에 확신이 없어 확인할 질문으로 남겨 두었다.

## 12. 읽으며 든 생각

### 구간 안의 i.i.d. 가정

가장 먼저 걸린 것은 구간 안의 데이터가 i.i.d.라는 가정이다. 각 구간의 데이터를 $\eta_\rho$로 정해지는 분포에서 독립적으로 뽑는다는 것은 시간적 상관(temporal correlation)을 배제한다는 뜻이다. 그런데 시계열은 일반적으로 자기상관을 가진다.

이 가정 아래에서는 모델이 change point를 찾는 데만 집중하게 되고, 점진적인 변화(gradual drift)나 짧은 기간의 일시적인 패턴 변화는 잘 반영되지 않는다. "가장 최근의 change point"를 찾는 데는 효과적이지만, 시계열 안의 점진적 변화나 장기적인 의존성을 모델링하는 데는 한계가 있다고 보았다.

DTF-net 논문도 BOCPD의 한계로 같은 점과 hyperparameter에 대한 민감성을 든다. 또 확률 기반 방법이 extreme value를 outlier로 취급해 주로 mean shift만 잡아낸다고 지적한다. 이 부분은 [Change point detection 개요](../study/trend-filtering-cpd/03-change-point-detection-overview.md)에 정리했다.

### Hazard function

기하분포를 쓰면 hazard가 상수가 되어 계산이 간단해지지만, 그것은 "change point는 언제든 같은 확률로 일어난다"는 가정이다. Hazard function을 더 유연하게 모델링하면 현실의 사건을 더 잘 반영할 수 있지 않을까 하는 생각이 들었다.

### 분포와 prior를 정해야 한다

BOCPD는 데이터가 어떤 분포에서 나오는지, 그 parameter의 prior가 무엇인지, change point가 얼마나 자주 일어나는지를 미리 정해야 한다. Trend filtering과 비교하면 이것이 가장 큰 차이로 보였다. 둘 다 급격한 변화를 찾는다는 점에서는 닮았지만, BOCPD는 생성 분포에 대한 가정 위에서 동작한다. 이 비교는 [용어 정리 글](../study/trend-filtering-cpd/04-change-point-terms.md)에서 이어진다.

## 남았던 질문과 답

공부할 당시에는 풀지 못하고 남겨 둔 질문들이다. 글을 정리하면서 답을 찾아 덧붙였다.

**Q. 재귀식의 predictive 항에서 조건 $x_{1:t-1}$이 $x_t^{(r)}$로 줄어드는 것은 논문이 둔 가정인가, 다른 가정에서 유도되는 것인가?**

별도의 가정이 아니라 product partition model에서 따라 나오는 결과다. 논문은 재귀식 바로 아래에 "predictive 분포는 최근 데이터 $x_t^{(r)}$에만 의존한다"고 한 줄로 적고 증명은 싣지 않는다. 근거는 1절의 두 가정이다. 구간 안의 데이터는 그 구간의 $\eta$가 주어지면 i.i.d.이고, 구간마다 $\eta$는 서로 독립이다. Run length를 알면 현재 구간이 어디서 시작했는지가 정해지고, 그 이전의 데이터는 다른 $\eta$에서 나왔으므로 현재 구간의 $\eta$에 대해 아무 정보도 주지 않는다.

$$
P(x_t \mid r_{t-1}, x_{1:t-1}) = \int P(x_t \mid \eta)\,P(\eta \mid r_{t-1}, x_{1:t-1})\,d\eta = \int P(x_t \mid \eta)\,P(\eta \mid x_t^{(r)})\,d\eta
$$

**Q. Run length와 데이터가 있으면 구간의 parameter에 대한 posterior를 안다고 보는 근거는 무엇인가?**

Run length가 현재 구간에 속한 데이터를 확정해 주고, 그 데이터는 prior가 알려진 하나의 $\eta$에서 i.i.d.로 나왔다고 가정하므로, 베이즈 정리만으로 posterior가 정해진다.

$$
P(\eta \mid r_t, x_t^{(r)}) \propto P(\eta) \prod_{x \in x_t^{(r)}} P(x \mid \eta)
$$

Conjugate prior를 쓰면 이 posterior가 닫힌 형태가 되고, hyperparameter는 $\nu = \nu_{\text{prior}} + r_t$, $\chi = \chi_{\text{prior}} + \sum u(x)$다. 논문의 식 (12), (13)이다.

**Q. Conjugate prior로 posterior를 구할 때 $\eta$와 무관한 항을 버리고 비례식만 구했다. 정규화 상수까지 구해야 제대로 된 분포가 아닌가?**

정규화 상수는 버린 것이 아니라, 따로 계산할 필요가 없는 것이다. 비례식 $g(\eta)^{\nu'}\exp\{\eta^\top \chi'\}$는 prior와 같은 함수 형태다. 그 형태의 분포를 정규화하는 상수는 prior에서 이미 $f(\chi, \nu)$로 알려져 있으므로, hyperparameter만 바꾸어 넣으면 된다.

$$
p(\eta \mid X, \chi, \nu) = f(\chi', \nu')\, g(\eta)^{\nu'} \exp\{\eta^\top \chi'\}
$$

이것이 켤레 관계의 이점이다. 예를 들어 Bernoulli likelihood와 Beta prior에서 비례식 $\theta^{a+k-1}(1-\theta)^{b+n-k-1}$을 얻으면, 적분하지 않아도 $\text{Beta}(a+k,\ b+n-k)$이고 정규화 상수가 $1/B(a+k,\ b+n-k)$임을 안다. Predictive도 같은 상수의 비로 닫힌 형태가 된다.

$$
p(x \mid X) = \int p(x \mid \eta)\,p(\eta \mid X)\,d\eta = h(x)\,\frac{f(\chi', \nu')}{f(\chi' + u(x),\ \nu' + 1)}
$$

**Q. 블로그는 conjugate prior의 식을 설명하며 "$\eta$와 $g(\eta)$는 앞과 같다"고 한다. 무엇이 같다는 뜻인가?**

바로 앞에 나온 지수족 likelihood $p(x \mid \eta) = h(x)\,g(\eta)\exp\{\eta^\top u(x)\}$의 $\eta$, $g(\eta)$와 같다는 뜻이다. Prior는 likelihood의 natural parameter $\eta$에 대한 분포이고, likelihood를 정규화하던 함수 $g(\eta)$를 그대로 가져와 $\nu$제곱한 형태로 만든다. 새로 등장하는 것은 hyperparameter $\chi$, $\nu$와 정규화 상수 $f(\chi, \nu)$뿐이다. 같은 $g$를 쓰기 때문에 likelihood와 곱했을 때 지수끼리 더해져 다시 같은 형태가 된다.

**Q. 재귀식이 hidden Markov model의 forward 알고리즘과 닮았다고 할 때, $r_t$를 어떤 잠재 변수로 보는 것인가?**

$r_t$가 HMM의 hidden state 자리에 온다. Forward 알고리즘은 $\alpha_t(j) = P(z_t = j, x_{1:t})$를 다음과 같이 재귀적으로 구한다. $a_{ij}$는 전이 확률, $b_j$는 방출 확률이다.

$$
\alpha_t(j) = b_j(x_t) \sum_i \alpha_{t-1}(i)\, a_{ij}
$$

BOCPD에서는 $\alpha_t$가 joint 확률 $P(r_t, x_{1:t})$(message), 전이 확률이 changepoint prior $P(r_t \mid r_{t-1})$, 방출 확률이 predictive 확률에 대응한다. 다만 표준적인 HMM과는 두 가지가 다르다. State가 가질 수 있는 값이 $0, \dots, t$로 시점마다 늘어난다. 그리고 방출 분포가 state마다 고정되어 있지 않고, 그 run에 속한 과거 관측값에 의존한다. 그래서 "같다"가 아니라 "닮았다"고 하는 것이다.

**Q. 데이터가 늘어날수록 posterior가 갱신된다면, 과거에 일어났다고 본 change point의 위치도 시점마다 달라지는가?**

"가장 최근의 change point가 언제였는가"에 대한 판단은 달라질 수 있다. $P(r_t \mid x_{1:t})$는 시점마다 새로 계산되는 분포이고, 마지막 change point의 위치는 $t - r_t$로 읽기 때문이다. 예를 들어 $t = 10$에서는 $r = 3$의 확률이 가장 높았는데, 데이터가 더 들어온 $t = 12$에서는 $r = 12$의 확률이 가장 높을 수 있다. 이 경우 $t = 7$ 부근의 change point는 없었던 것으로 판단이 바뀐 것이다. 반면 이미 계산한 과거 시점의 분포 $P(r_s \mid x_{1:s})$를 나중 데이터로 고쳐 쓰지는 않는다. 과거 시점의 run length를 전체 데이터로 다시 추정하려면 뒤에서 앞으로 가는 계산이 따로 필요하고, 논문은 이런 회고적 분할이 아니라 현재 시점의 추정(causal predictive filtering)을 목표로 한다고 밝힌다.

**Q. BOCPD는 지점을 확정해 주지 않는다. 다른 방법과 비교하는 실험에서는 확률이 가장 높은 지점을 change point로 삼는 것인가?**

논문은 규칙을 정하지 않는다. 실험에서도 run length posterior의 그림을 보여 주고, run length가 0으로 떨어지는 곳이 실제 변화와 잘 맞는다고 설명할 뿐이며, 다른 방법과의 정량 비교는 없다. 지점이 필요하면 후처리 규칙을 정해야 한다. 흔히 쓰는 것은 각 시점에서 확률이 가장 높은 run length가 급격히 줄어드는 곳을 change point로 보는 방식과, 몇 시점 뒤에 "run length가 그 사이에 지난 시점 수와 같다"는 확률이 임계값을 넘는지를 보는 방식이다. 주의할 점은 hazard가 상수 $H$일 때 $P(r_t = 0 \mid x_{1:t})$가 데이터와 무관하게 항상 $H$라는 것이다. 9절의 4, 5단계에서 growth 확률의 합과 changepoint 확률이 같은 합 $\sum_{r_{t-1}} P(r_{t-1}, x_{1:t-1})\,\pi_t^{(r)}$에 각각 $1 - H$와 $H$를 곱한 것이기 때문이다. 그래서 "run length가 0일 확률"을 그대로 임계값과 비교하는 방식은 쓸 수 없다.

**Q. 이전 연구인 CUSUM 등과 비교해 BOCPD는 무엇을 새로 가능하게 했는가?**

논문의 정리에 따르면 online 탐지는 Page, Lorden의 연구 같은 빈도주의 방법에 이미 있었고, Bayesian 방법은 대부분 offline이었다. BOCPD가 더한 것은 online으로 동작하는 Bayesian 추론이다. CUSUM은 변화 전후 분포의 log-likelihood ratio를 누적한 통계량 $S_t = \max\big(0,\ S_{t-1} + \log\frac{p_1(x_t)}{p_0(x_t)}\big)$가 임계값을 넘으면 경보를 낸다. 출력은 경보 시점 하나이고, 변화 전후의 분포와 임계값을 미리 정해야 한다. BOCPD는 매 시점 run length 전체에 대한 posterior를 정확하게 계산하므로 불확실성까지 함께 주고, 다음 데이터의 predictive 분포를 내놓는다. 변화 후의 parameter는 값을 정해 두지 않고 prior로 주변화한다. 논문은 여기에 더해 change point 알고리즘과 데이터 모델의 구현이 분리되어 모델을 갈아 끼울 수 있다는 점을 장점으로 든다.
