# AttnLRP: Attention-Aware Layer-Wise Relevance Propagation for Transformers

LRP(Layer-wise Relevance Propagation)를 Transformer에 적용할 수 있도록 확장한 논문이다. LRP를 이름만 아는 상태에서 읽기 시작했기 때문에, 먼저 필요한 용어를 정리하고 논문을 따라갔다. 전파 규칙의 수식은 논문에서 옮겨 적었고, 그 옆에 내가 이해한 의미를 붙였다. 당시 끝까지 이해하지 못한 부분은 "남았던 질문과 답"에 모았다.

## 한 줄 요약

Softmax, attention의 행렬 곱, 정규화 layer에 대한 LRP 전파 규칙을 새로 만들어, backward pass 한 번으로 Transformer의 입력과 내부 뉴런 모두에 대한 attribution을 구한다.

## 먼저 정리한 용어

| 용어 | 뜻 |
|---|---|
| Attribution | 모델의 출력에 입력 feature가 기여한 정도를 추적하고 정량화하는 것. 입력뿐 아니라 중간 layer의 뉴런에 대해서도 구할 수 있다 |
| LRP | 신경망의 출력값을 입력에 대한 기여도로 분해하는 기법. 각 layer에서 relevance를 계산해 이전 layer로 전파한다 |
| Relevance | 출력에 대한 상대적 중요도. 이미지 분류라면 어떤 픽셀이 "개"라는 예측에 얼마나 기여했는지 |
| Conservation property | Relevance의 합이 모든 layer에서 같게 유지되는 성질. 출력 layer의 relevance가 100이면 입력 layer의 합도 100이어야 한다 |
| Additive explanatory model | 출력을 개별 입력 feature의 기여도의 합으로 표현하는 설명 모델. Shapley value, Gradient × Input, DeepLIFT, LRP가 여기에 속한다 |
| Deep Taylor Decomposition | 각 연산을 국소적으로 선형화해 relevance를 분해하는 방법. LRP에서 비선형 연산을 다루는 틀이다 |
| Bias absorption | 비선형 함수를 선형화할 때 생기는 bias 항으로 relevance의 일부가 흡수되는 현상 |
| ActMax | Activation Maximization. 특정 뉴런을 가장 강하게 활성화하는 입력 샘플을 찾아, 그 뉴런이 학습한 개념을 파악한다 |

Conservation property가 중요한 이유는 이렇게 이해했다. Relevance의 합이 layer마다 일정하게 유지되기 때문에, relevance의 비율을 그대로 출력에 대한 상대적 기여도로 읽을 수 있다.

Transformer에서 문제가 되는 구성 요소도 미리 적어 두었다.

- **Softmax**: 벡터를 확률 분포로 바꾸는 비선형 함수. 비선형이라 relevance를 전파하기 어렵다.
- **행렬 곱**: query, key, value 사이의 행렬 연산. 두 입력의 곱이라서 출력의 relevance를 두 입력에 어떻게 나눌지 정해야 한다.
- **정규화 layer**: LayerNorm은 평균과 분산으로, RMSNorm은 평균 없이 L2 norm으로 정규화한다. 비선형 연산이라 relevance 전파가 복잡해진다.

## 문제의식

Transformer는 대규모 학습에 유리한 attention 덕분에 텍스트와 이미지 생성에서 좋은 성과를 냈지만, 편향된 출력이나 hallucination을 만들어 낼 가능성이 있다. 이를 다루려면 모델 내부의 추론 과정(latent reasoning process)을 알아야 한다.

기존 방법은 각각 한계가 있다.

**Attention 기반.** Attention weight는 모델에 대한 해석을 일부 주지만 그것만으로는 충분하지 않다. Class specificity가 부족하고 최종 예측에 대한 의미 있는 해석을 주지 못한다. 최근 연구는 factual knowledge가 attention이 아니라 feed-forward network의 뉴런에 저장된다는 것을 밝혔다. Rollout 같은 attention 기반 attribution은 Vision Transformer에서 checkerboard artifact를 만든다. 여기서 artifact는 자연스럽지 못한 무늬를 말한다.

**Perturbation과 local surrogate.** 입력 feature를 반복해서 perturbation하면서 출력의 변화를 본다. Occlusion 기반 attribution과 SHAP이 여기에 속한다. AtMan은 입력 토큰을 가리는 대신 latent 공간의 attention weight를 억제한다. LIME, LORE 같은 local surrogate는 복잡한 black box 모델을 복잡도가 낮은 선형 모델로 대체해 설명한다. 이 방법들은 model-agnostic이라는 장점이 있지만 forward pass를 많이 요구해 계산 비용이 높다. 내부 뉴런에 대한 attribution을 얻으려면 layer마다 따로 perturbation해야 하므로 비용이 더 크게 늘어난다. Surrogate 모델이 만든 설명에는 hidden representation에 대한 정보도 없다.

**Gradient 기반.** Chain rule 덕분에 backward pass 한 번으로 모든 layer에 대한 값을 얻는다. Input × Gradient 같은 방법은 매우 효율적이다. 그러나 gradient가 noisy하면 영향을 그대로 받고 faithfulness가 낮다. 신경망이 깊어질수록 gradient가 잡음처럼 변하는 gradient shattering 때문에 noise를 피하기 어렵다.

**LRP.** 규칙 기반 backpropagation 방법이다. Backward pass 한 번만 필요하면서 더 충실한 설명을 줄 수 있다. 그러나 표준 LRP는 Transformer에 그대로 적용할 수 없다. Softmax, query와 key의 bi-linear 곱, layer normalization 때문이다.

논문의 기여는 세 가지다.

1. Deep Taylor Decomposition의 틀 안에서 비선형 attention에 대한 효율적이고 충실한 LRP 규칙을 유도한다. 기존 방법보다 우수함을 보이고 ViT의 noise 문제도 다룬다.
2. 예측에 관련된 뉴런을 찾고 그 뉴런이 무엇을 인코딩하는지 설명함으로써 LLM의 생성 과정을 들여다보는 방법을 보인다.
3. Transformer용 AttnLRP의 오픈소스 구현을 제공한다.

## 방법

### LRP와 선형화

LRP는 additive explanatory model에 속한다. 이 계열의 가정은, 입력 feature가 $N$개인 함수 $f_j$의 출력을 각 입력 변수의 기여로 분해할 수 있다는 것이다.

$$
f_j(\mathbf{x}) \propto R_j = \sum_i^N R_{i \leftarrow j}
$$

$R_{i \leftarrow j}$는 출력 $j$의 relevance 가운데 입력 $i$에 배분되는 몫이다.

분해는 선형화로 얻는다. $f_j$를 기준점 $\mathbf{x}$에서 1차 Taylor 급수로 근사한다.

$$
f_j(\mathbf{x}) = \sum_i \mathbf{J}_{ji}\, x_i + \tilde{b}_j
$$

$\mathbf{J}_{ji}$는 기준점에서 계산한 Jacobian으로, 입력 $i$가 출력 $j$에 미치는 민감도다. $\tilde{b}_j$는 Jacobian 항으로 설명되지 않는 나머지를 모은 bias 항이다. 이 식의 양변에 $R_j / f_j(\mathbf{x})$를 곱하면 relevance의 분배가 된다.

$$
R_j = f_j(\mathbf{x})\, c = \sum_i \underbrace{\mathbf{J}_{ji}\, x_i\, \frac{R_j}{f_j(\mathbf{x})}}_{R_{i \leftarrow j}} + \underbrace{\tilde{b}_j\, \frac{R_j}{f_j(\mathbf{x})}}_{R_{b \leftarrow j}}
$$

$R_{i \leftarrow j}$는 입력 변수에 배분된 relevance, $R_{b \leftarrow j}$는 bias 항에 배분된 relevance다. Bias가 relevance를 흡수하는 문제는 두 가지 방식으로 처리할 수 있다. Bias를 별도의 숨겨진 뉴런으로 보아 relevance를 유지하거나, bias의 몫을 입력 변수들에 균등하게 나누어 conservation을 엄격히 지키는 것이다.

입력 $i$의 relevance는 연결된 모든 출력에서 온 몫을 더한 것이다. 분모가 0에 가까워질 때를 대비해 작은 값 $\varepsilon$을 더한다.

$$
R_i = \sum_j R_{i \leftarrow j} = \sum_j \mathbf{J}_{ji}\, x_i\, \frac{R_j}{f_j(\mathbf{x}) + \varepsilon\, \text{sign}(f_j(\mathbf{x}))}
$$

### MLP

MLP는 가중치를 곱하고 bias를 더하는 linear layer와 activation으로 이루어진다.

**$\varepsilon$-LRP.** Linear layer에서는 Jacobian이 가중치 $W_{ji}$이므로 위의 식이 다음과 같이 된다. $z_j$는 linear layer의 출력이다.

$$
R_i^{l-1} = \sum_j \frac{W_{ji}\, x_i\, R_j^{l}}{z_j(\mathbf{x}) + \varepsilon \cdot \text{sign}(z_j(\mathbf{x}))}
$$

입력 $x_i$와 가중치 $W_{ji}$의 곱이 클수록 그 입력에 더 많은 relevance가 배분된다. $z_j$로 나누는 것은 몫의 합이 $R_j$가 되도록 맞추는 정규화로 이해했다.

**$\gamma$-LRP.** 깊은 모델에서는 relevance 분배에 noise가 생길 수 있고 ViT에서 특히 두드러진다. $\gamma$-LRP는 relevance의 신호 대 잡음비를 개선하는 규칙으로, 주로 ViT에 쓴다.

**Element-wise 비선형.** Activation 함수는 입력과 출력이 일대일로 대응하므로 relevance를 그대로 전달한다. 논문은 이것을 identity rule이라고 부른다.

### Attention

Attention은 행렬 곱과 softmax를 포함하므로 relevance를 충실하게 분배하려면 별도의 규칙이 필요하다.

**Softmax.** Softmax는 강한 비선형 함수라 relevance를 정확히 분해하기 어렵다. Taylor 선형화를 적용해 다음 규칙을 얻는다. $x_i$는 softmax의 입력, $s_i$는 출력이다.

$$
R_i^{l-1} = x_i \Big( R_i^{l} - s_i \sum_j R_j^{l} \Big)
$$

Relevance가 softmax의 출력과 입력의 상대적 기여에 따라 분배된다는 뜻으로 읽었다. 이 규칙은 선형화에서 나오는 bias 항을 버리지 않고 활용한다.

**행렬 곱.** 두 입력 $A$, $B$를 곱해 출력을 계산할 때, 한쪽을 상수로 고정하면 다른 쪽에 대해 선형인 연산을 bi-linear라고 한다. 이 연산에서는 출력에 대한 두 입력의 기여가 서로 종속되어 있어서 relevance를 각각으로 나누기가 쉽지 않다. 0이나 매우 작은 값으로 나누게 되면 수치적으로도 불안정해진다. 표준 LRP 규칙은 단순한 선형 연산이나 element-wise 연산을 위해 만들어졌고 bi-linear 연산에는 대응하지 못한다.

AttnLRP는 attention weight $A$와 value $V$의 곱 $O_{jp} = \sum_i A_{ji} V_{ip}$에 대해 다음과 같이 분배한다.

$$
R_{ji}^{l-1} = \sum_p \frac{A_{ji}\, V_{ip}\, R_{jp}^{l}}{2\, O_{jp} + \varepsilon}
$$

각 항 $A_{ji} V_{ip}$가 출력 $O_{jp}$에서 차지하는 비율만큼 relevance를 나눈다. 분모의 2는 곱에 참여한 두 입력에 relevance를 균등하게 나누는 uniform propagation에서 나온다.

**정규화 layer.** LayerNorm과 RMSNorm은 평균이나 분산 계산을 포함하는 비선형 연산이다. 여기서 relevance를 분배하면 대부분이 bias로 흡수될 위험이 있다. Taylor 선형화로 정규화 layer를 linear layer처럼 단순화하면 relevance를 변형 없이 그대로 전달하는 identity rule이 된다. 추가 계산 없이 conservation이 유지된다.

### 내부 뉴런 이해하기

LRP는 출력에서 입력까지 relevance를 전파하므로 중간의 모든 뉴런에 대해서도 relevance가 구해진다. 이것을 두 가지와 결합한다.

- **ActMax**: 특정 뉴런을 가장 강하게 활성화하는 입력을 찾아, 그 뉴런이 어떤 개념을 학습했는지 파악한다.
- **Relevance attribution**: LRP로 그 뉴런의 활성화와 가장 관련이 깊은 입력 토큰을 찾는다.

ActMax로 뉴런을 활성화하는 샘플을 찾은 뒤 AttnLRP로 그 샘플의 어느 토큰이 중요한지 분석하면 뉴런의 기능을 이해할 수 있다.

### 정리

| 구성 요소 | 규칙 |
|---|---|
| Linear layer | $\varepsilon$-LRP 또는 $\gamma$-LRP |
| Activation 함수 | Identity rule |
| Softmax | Taylor decomposition 기반 규칙. Bias 항을 활용 |
| 행렬 곱 | 두 입력에 균등하게 나누는 uniform propagation |
| LayerNorm, RMSNorm | Identity rule |

## 실험과 결론

실험은 세 가지 질문에 답하도록 구성되어 있다.

- 다른 최신 방법과 비교해 설명이 얼마나 충실한가(faithful)?
- Perturbation 기반 방법과 비교해 LRP는 얼마나 효율적인가?
- Latent representation을 이해하고 LLM과 상호작용할 수 있는가?

논문의 결론은 LRP를 softmax와 행렬 곱이라는 비선형 attention 연산으로 확장했고, 그 규칙에 Deep Taylor Decomposition에 따른 해석을 주었다는 것이다. AttnLRP는 단순하고, 충실하고, backward pass 한 번만 필요해 효율적이다. LLM과 ViT 모두에 적용할 수 있고, ViT에서는 $\gamma$ 규칙으로 noise를 줄인다. 다른 backpropagation 기반 방법과 달리 latent 공간과 attention module에 대해서도 정확한 attribution을 준다.

## 읽으며 가진 질문과 찾은 답

**Attribution method가 정확히 무엇을 가리키는가?** 논문에서 말하는 attribution method는 input attribution이다. Activation에 기여한 입력을 찾아내는 방법이다.

**선형화의 기준점 $\mathbf{x}$는 어떻게 정해지는가?** 식에 나오는 Jacobian은 기준점 $\mathbf{x}$에서 계산한, $j$번째 출력에 대한 $i$번째 입력의 Jacobian이다. $\mathbf{J}_{ji}$는 $i$에서 $j$로의 민감도이고, 전치하면 반대 방향이 된다.

**Bias는 어디서 나오는가?** Jacobian 항만 남기고 나머지를 bias로 보는 것이며, Taylor 근사의 결과다.

**분모에 $\varepsilon\,\text{sign}(\cdot)$을 더하는 이유는?** 분모가 작을 때를 대비해 부호를 맞추어 더해 주는 안정화 장치다.

**표준 LRP는 왜 Transformer에 적용할 수 없는가?** 서론을 읽을 때는 이유를 알 수 없다고 적었다. 3장을 읽고 나서 정리한 답은 세 가지다. Softmax는 강한 비선형이라 relevance를 분해하기 어렵다. Query와 key의 곱은 bi-linear여서 두 입력의 기여가 종속되어 있다. 정규화 layer에서는 relevance가 bias로 흡수된다. 표준 규칙은 단순한 선형 연산과 element-wise 연산만 가정하고 만들어졌다.

**행렬 곱 규칙의 2는 무엇인가?** 처음에는 "균등하게 더하니까 2로 나누는 것인가" 하고 물음표를 붙여 두었다. 논문 전체를 다시 요약하면서, 두 입력에 relevance를 균등하게 나누는 uniform propagation이라는 것으로 정리했다.

## 남았던 질문과 답

공부할 당시에는 풀지 못하고 남겨 둔 질문들이다. 글을 정리하면서 답을 찾아 덧붙였다.

**Q. Transformer가 편향되거나 hallucination을 만들어 내기 쉬운 이유는 무엇인가?**

논문은 이유를 설명하지 않는다. 서론에서 hallucination에 대한 survey(Huang et al., 2023)를 인용하며 그런 경향이 있다고 적을 뿐이다. 일반적으로 알려진 설명은 구조보다 학습 방식에 있다. 언어 모델은 학습 데이터에서 다음 토큰의 likelihood를 높이도록 학습되므로, 데이터에 들어 있는 치우침을 그대로 배운다. 이것이 편향이다. 또 이 목적 함수가 보상하는 것은 "사실인 문장"이 아니라 "그럴듯하게 이어지는 문장"이고, 모델은 모르는 내용에 대해서도 항상 어떤 토큰이든 내놓아야 한다. 그래서 사실과 다른 내용을 유창하게 생성할 수 있다. 이것이 hallucination이다. 따라서 Transformer라는 구조의 성질이라기보다, 대규모 데이터로 likelihood를 최대화해 학습한 생성 모델의 성질로 보는 것이 일반적이다.

**Q. Faithfulness가 낮다는 것은 정확히 무엇을 뜻하고, 어떻게 측정하는가?**

Faithfulness는 설명이 모델의 실제 계산을 얼마나 정확히 반영하는가를 말한다. 모델 예측의 신뢰도가 아니고, 사람이 보기에 그럴듯한가(plausibility)와도 다른 개념이다. 논문은 분해가 faithful하려면 원래 함수의 특성을 가능한 한 가깝게 근사해야 한다고 쓴다. 측정은 input perturbation 실험으로 한다. Attribution이 높은 토큰부터 baseline 값으로 바꾸어 가면(MoRF, most relevant first) 모델의 출력이 빨리 떨어져야 하고, 낮은 토큰부터 바꾸면(LeRF, least relevant first) 천천히 떨어져야 한다. 논문은 두 perturbation 곡선 아래 넓이의 차이를 점수로 쓴다.

$$
\Delta A^{F} = A^{F}_{\text{LeRF}} - A^{F}_{\text{MoRF}}
$$

값이 클수록 faithful한 설명이다. "Gradient 기반 방법의 faithfulness가 낮다"는 말은 이 점수가 낮다는 뜻이다. 논문의 Table 1에서 ViT-B-16(ImageNet)의 점수는 Input × Gradient가 0.80, AttnLRP가 6.19다.

**Q. 저자가 softmax에서 bias 항을 포함해야 한다고 주장하는 이유는 무엇인가? Softmax를 선형화하면 반드시 bias가 생기는가?**

논문의 근거는 입력이 모두 0이어도 softmax는 $1/N$을 출력한다는 것이다. 입력에 귀속시킬 수 없는 이 몫이 가상의 bias에 해당한다고 본다. 반대로 $f(0) = 0$인 RMSNorm이나 행렬 곱은 bias 없이 분해하는 것이 맞다고 한다. 식으로 보아도 그렇다. 기준점 $\mathbf{x}$에서 선형화하면 bias는 $\tilde{b}_j = f_j(\mathbf{x}) - \sum_i \mathbf{J}_{ji} x_i$다. Softmax의 Jacobian $\mathbf{J}_{ji} = s_j(\delta_{ij} - s_i)$를 넣으면 다음과 같다.

$$
\sum_i \mathbf{J}_{ji}\, x_i = s_j \Big( x_j - \sum_i s_i x_i \Big), \qquad \tilde{b}_j = s_j \Big( 1 - x_j + \sum_i s_i x_i \Big)
$$

$\tilde{b}_j$가 0이 되는 것은 $x_j - \sum_i s_i x_i = 1$인 특수한 경우뿐이므로 bias는 사실상 항상 생긴다. $\mathbf{x} = 0$이면 Jacobian 항이 모두 0이고 출력 $1/N$ 전체가 bias다. 논문은 이 bias를 억지로 없애는 기존 방식(입력에 균등하게 나누거나 identity rule을 쓰는 방식)이 값이 0인 입력에도 relevance를 주게 되고, 다음 단계에서 0에 가까운 값으로 나누게 되어 수치적으로 불안정해진다고 설명한다.

**Q. Bi-linear 연산에서 relevance를 나누기 어려운 이유는 무엇인가?**

$\varepsilon$-LRP는 한쪽이 변수이고 다른 쪽은 고정된 가중치인 linear layer를 가정한다. 곱에서는 양쪽이 모두 변수다. $A$를 변수로, $V$를 가중치로 보고 규칙을 적용하면 $A$가 relevance 전체를 받고, 반대로 보면 $V$가 전체를 받는다. 둘을 합치면 $2R$이 되어 conservation이 깨진다. 논문 부록 A.3.5의 증명이 이 내용이다. 작은 예로 $f = a \cdot v$, $a = 2$, $v = 3$이면 $f = 6$인데 두 입력의 Gradient × Input은 $\frac{\partial f}{\partial a} a = 6$, $\frac{\partial f}{\partial v} v = 6$으로 합이 $12 = 2f$다. 일반적으로 $N$개 변수의 곱에서는 이 합이 $N f$가 되므로 선형화에 $\tilde{b} = (1 - N) f$라는 bias가 생긴다. 논문은 이 bias를 입력들에 균등하게 나누면 각 입력이 $R/N$을 받는 uniform rule이 나온다는 것을 보이고, baseline을 0으로 둔 Shapley value로도 같은 결과가 나온다고 한다. 행렬 곱에서는 $N = 2$여서 분모에 2가 들어간다.

**Q. $\gamma$-LRP의 구체적인 식은 무엇인가?**

논문 부록 A.2.3에 있다. 입력 $i$가 출력 $j$에 주는 기여를 $z_{ij} = W_{ji} x_i$, 출력을 $z_j$라고 하면 다음과 같다.

$$
R_{i \leftarrow j} =
\begin{cases}
\dfrac{z_{ij} + \gamma\, z_{ij}^{+}}{z_j + \gamma \sum_k z_{kj}^{+}}\, R_j & z_j > 0 \\[2ex]
\dfrac{z_{ij} + \gamma\, z_{ij}^{-}}{z_j + \gamma \sum_k z_{kj}^{-}}\, R_j & \text{그 밖의 경우}
\end{cases}
$$

$(\cdot)^{+} = \max(\cdot, 0)$, $(\cdot)^{-} = \min(\cdot, 0)$이고 $\gamma > 0$이다. 출력과 같은 부호의 기여에 가중치를 더 주어, 반대 방향의 기여가 서로 상쇄되면서 생기는 noise를 줄인다. $\gamma = 0$이면 $\varepsilon$을 뺀 $\varepsilon$-rule과 같고, $\gamma \to \infty$이면 양의 기여만 쓰는 $z^{+}$-rule이 된다. 예를 들어 기여가 $(+3, -2)$이고 $z_j = 1$, $R_j = 1$이면 $\gamma = 0$일 때 $(3, -2)$, $\gamma = 0.25$일 때 약 $(2.14, -1.14)$, $\gamma \to \infty$일 때 $(1, 0)$으로 나뉜다. 합은 모두 1로 같고 서로 상쇄되는 크기만 줄어든다. 논문이 ViT에 쓴 값은 convolution layer에 $\gamma = 0.25$, linear layer에 $\gamma = 0.05$이고, attention 안의 projection layer에는 $\varepsilon$-rule을 쓴다. 논문은 $\gamma$를 모델과 데이터에 맞게 조정해야 한다고 적는다.
