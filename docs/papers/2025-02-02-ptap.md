# Interpreting Internal Activation Patterns in Deep Temporal Neural Networks by Finding Prototypes

시계열 데이터를 다루는 CNN의 내부 채널이 입력의 어떤 모양에 반응하는지를, 사람이 붙인 label 없이 보여 주는 방법(PTAP)을 제안한 논문이다. 이 방법은 시계열 XAI 강의에서 처음 접했고([XAI 개요](../study/xai/01-xai-overview.md)), 2025년 1월에 서론과 3장을 한 번 훑은 뒤 2월에 처음부터 다시 읽었다. 이 글은 2월의 기록이다. 논문의 흐름을 정리한 뒤, 읽으면서 막혔던 정의 세 가지를 예시로 풀고, 마지막에 "그래서 이 논문이 새로 보여 주는 것이 무엇인가"에 대한 내 생각을 적는다.

## 한 줄 요약

채널에서 강하게 활성화된 노드의 receptive field를 모으고, 그 가운데 분포를 대표하는 구간을 MMD로 골라, 그 채널이 학습한 시계열 패턴의 원형(prototype)으로 보여 준다.

## 문제의식

시계열 모델은 의사결정 과정이 불투명해서 산업 현장에서 신뢰를 얻기 어렵다. 딥러닝 해석 기법은 주로 이미지를 대상으로 연구되었고 시계열에 대한 연구는 부족하다. 이유는 데이터의 성격에 있다. 이미지에는 물체별 segmentation label처럼 분명한 의미 정보가 있다. 시계열에는 시간 구간별로 의미를 붙인 annotation이 거의 없고, 그것을 만들려면 도메인 지식이 필요하다. 그래서 신경망이 시계열에서 찾아낸 semi-global한 모양을 끌어내기가 어렵다.

논문은 기존 해석 방법을 다섯 갈래로 나누고 각각이 시계열에 맞지 않는 이유를 든다.

| 갈래 | 내용 | 시계열에서의 문제 |
|---|---|---|
| Input attribution | Relevance score로 각 입력 요소의 기여를 측정한다. LRP, gradient 기반 방법 | 주로 이미지를 대상으로 연구되었고, 시계열에서는 해석이 불명확하다 |
| Internal node 설명 | 특정 채널이 무엇을 학습했는지 해석한다. Network Dissection | Segmentation label이 필요한데 시계열에는 구간별 label이 없다 |
| Attention | Attention score로 의사결정을 해석한다 | CNN, RNN 기반 모델에는 적용하기 어렵다 |
| Example-based | 데이터를 대표하는 사례(prototype)로 설명한다. K-medoids, MMD-critic | 유클리드 거리에 기반해 시간 방향의 shift에 민감하다 |
| 설명 생성 | 모델이 스스로 설명을 생성한다 | 시계열의 세부적인 해석을 자동으로 만들기는 아직 어렵다 |

이 논문은 두 번째와 네 번째를 합친다. Network Dissection처럼 채널 단위로 내부를 보되, label 대신 prototype을 쓴다. 과정은 세 단계다.

1. 중요한 subsequence를 찾는다.
2. 찾은 subsequence들 가운데 대표적인 것을 prototype으로 고른다.
3. 시각화해서 내부 채널이 무엇을 하는지 보여 준다.

기여로 내세우는 것은 다음과 같다.

- Segmentation label 없이 CNN의 채널을 가장 강하게 활성화하는 대표 subsequence를 제공한다.
- Greedy prototype selection을 개선한다. 제안한 방식은 subsequence의 shift에 덜 민감해서 시계열에 더 적합하다.
- 각 prototype 그룹에서 input attribution의 분포를 보여 주는 value-LRP plot을 제시한다. 채널이 모양의 어떤 부분에 주목하는지 설명하는 데 쓴다.

## 방법

### Temporally Activated Pattern

TAP(Temporally Activated Pattern)은 채널이 강하게 활성화된 지점에 대응하는 입력 구간이다.

1. CNN의 각 layer에서 채널별로 activation의 threshold를 정한다. Threshold는 상위 $\theta$ 비율의 activation이 넘도록 잡는다.
2. Threshold를 넘은 노드를 고른다.
3. 그 노드의 input receptive field, 즉 그 노드의 activation에 영향을 준 입력 subsequence를 찾는다. Convolution 연산이므로 receptive field는 해석적으로 계산할 수 있다.

결국 activation이 큰 노드를 기준으로, 입력 시계열에서 그 노드가 보고 있던 구간을 찾는다는 것이다. 이것을 데이터셋 전체에 대해 모으면 어떤 시간적 패턴이 반복해서 나타나는지 분석할 수 있다.

### Prototype 선택

모은 TAP 하나하나를 보는 대신, 전체 분포를 대표하는 몇 개를 고른다. 이것이 PTAP(Prototypes of Temporally Activated Patterns)이다. 선택에는 MMD(Maximum Mean Discrepancy)를 쓴다. MMD는 두 분포가 얼마나 다른지를 재는 척도다.

$$
\text{MMD}(F, P, Q) = \sup_{f \in F} \Big( \mathbb{E}_{x \sim P}[f(x)] - \mathbb{E}_{y \sim Q}[f(y)] \Big)
$$

$P$는 원래 데이터(TAP 전체)의 분포, $Q$는 선택한 prototype 집합의 분포다. MMD가 작아지도록 prototype을 고르면 원래 분포를 잘 대표하는 집합이 된다.

최적의 집합을 찾는 것은 계산이 어려우므로 greedy하게 고른다. 빈 집합에서 시작해, MMD를 가장 많이 줄이는 데이터를 하나씩 추가하는 과정을 반복한다. 이 선택은 submodular 함수 최적화 문제로 볼 수 있고, kernel matrix가 특정 조건(비음수성, 대각 우세성)을 만족하면 greedy 알고리즘이 최적에 가까운 해를 준다.

기존의 MMD 기반 prototype 선택은 유사도를 RBF kernel로 잰다. RBF kernel은 유클리드 거리에 기반하므로 시간 방향의 shift에 민감하다. 모양이 같은데 조금 밀린 두 패턴을 다른 것으로 본다. 논문은 RBF kernel 대신 CNN 내부 채널의 activation으로 만든 Gram kernel matrix를 쓴다. 이렇게 고른 prototype은 shift에 더 강인하고, 비슷한 패턴을 더 일관되게 묶는다.

### 시각화

원본 시계열 위에 채널이 주목한 부분을 겹쳐 그린다. 논문의 그림은 입력 시퀀스, 입력의 receptive field, PTAP, 변형 범위를 함께 그린 PTAP의 순서로 과정을 보여 준다. TAP이 발견된 구간을 표시하고, 그 그룹의 대표인 PTAP을 강조하고, 같은 그룹에 속한 TAP들의 변형 범위를 음영으로 표시한다. 이 그림으로 채널이 학습한 핵심 패턴이 무엇인지 볼 수 있다.

### 채널의 민감도 분석

채널이 어떤 구간에 반응하는지는 TAP으로 알 수 있다. 그러나 그 구간 안에서 정확히 어느 부분이 activation을 키웠는지는 알기 어렵다. 이것을 보려고 LRP를 쓴다. 채널의 activation을 출발점으로 relevance를 입력까지 전파해, 구간 안의 각 시점이 그 activation에 얼마나 기여했는지를 구한다.

결과는 두 가지 그림으로 본다.

- **Data-LRP plot**: 시계열 위에 시점별 LRP 점수를 함께 표시한다. 어느 시점이 activation에 크게 기여했는지 본다.
- **Value-LRP plot**: 가로축은 시계열의 값, 세로축은 그 값의 LRP 점수다. 어떤 값 범위에서 기여도가 높은지, 기여도가 어디서 급격히 변하는지를 본다.

합성 데이터에서 value-LRP plot을 그려 보면 채널마다 주목하는 부분이 다르다. 어떤 채널은 peak로 올라가는 부분을, 다른 채널은 peak 이후 내려가는 부분을 강조한다.

## 실험

데이터셋은 UWave(손동작 인식), FordA(자동차 엔진 센서), Starlight(천체 관측), HAR(스마트폰 센서 기반 활동 인식) 네 가지다. 모델은 convolution layer 3개에 pooling과 fully connected layer를 붙인 기본 CNN과, 9개 layer의 ResNet 기반 CNN이다.

- **Layer별 패턴.** 초기 layer(1 ~ 2)는 빠른 변화나 급격한 증가와 감소 같은 국소적인 패턴을 잡는다. 깊은 layer(3 이상)는 noise가 걸러진 더 전역적인 패턴을 잡는다.
- **Prototype 선택의 정량 평가.** K-medoids, RBF 기반 MMD, Gram kernel 기반 MMD, Gram kernel에 power scaling을 적용한 방식(Gram_p)을 비교한다. 선택한 prototype만으로 원래 label을 분류하는 logistic regression의 성능으로 prototype이 데이터를 얼마나 잘 대표하는지 잰다. Gram kernel 기반 방식이 기존 방식보다 좋았고 Gram_p가 가장 좋았다.
- **정성 평가.** RBF 기반 방식은 시간 방향으로 밀린 같은 패턴을 다른 그룹으로 나누는 경우가 있었다. Gram kernel 기반 방식은 비슷한 패턴을 일관되게 묶었다.
- **보지 않은 데이터.** 학습 데이터에서 얻은 PTAP은 새로운 테스트 데이터에서도 대체로 비슷한 패턴을 잡았다. 일부 데이터에서는 PTAP과 어긋나는 구간이 있었는데, 그 구간을 강조해 보여 주면 모델이 어려워하는 영역을 파악하는 데 쓸 수 있다.

## 읽으며 막혔던 정의 세 가지

처음 읽고 나서 남은 혼란은 두 가지였다. TAP이 정확히 무엇인가, 그리고 PTAP은 어떻게 정해지는가. 논문의 정의를 작은 예시로 다시 풀었다.

### 1. $H_{j,k}$: 강하게 활성화된 노드의 위치

Layer $j$의 채널 $k$마다 threshold $T_{j,k}$를 따로 정한다. 채널 $k$의 activation $a_{j,k}$의 분포에서 오른쪽 꼬리의 넓이가 $\theta$가 되는 지점이 $T_{j,k}$다.

$$
P\big(a_{j,k} > T_{j,k}\big) = \theta
$$

$H_{j,k}$는 이 threshold를 넘은 노드들의 temporal index 집합이다. Layer $j$에 채널이 3개 있고 채널마다 노드가 5개(temporal index 0 ~ 4) 있다고 하자. ●는 threshold를 넘은 노드다.

| | 0 | 1 | 2 | 3 | 4 | $H_{j,k}$ |
|---|---|---|---|---|---|---|
| 채널 1 | ● | | ● | | | $\{0, 2\}$ |
| 채널 2 | | ● | ● | | | $\{1, 2\}$ |
| 채널 3 | ● | | | ● | | $\{0, 3\}$ |

Threshold가 채널마다 다르므로 $H_{j,k}$도 채널마다 다르다. 논문의 개요 그림은 layer 2에 threshold를 적용해 $H_{j,k}$를 찾은 예로 보인다.

여기서 하나 더 확인한 것이 있다. 시계열 분류 CNN에서 어떤 layer의 노드 하나는 이전 layer의 여러 노드에서 영향을 받는다. Convolution이 시간적 의존성을 잡는 방식이다. 따라서 layer가 깊어져도 시간 축의 정보는 계속 유지된다.

### 2. TAP과 TAU

**TAP**은 $H$에 속한 각 노드의 receptive field다. 논문의 개요 그림에서 노드로부터 입력 쪽으로 거슬러 내려가 얻는 입력 구간이 TAP이다. 그 그림을 정의 그대로 받아들여도 되는지 궁금했는데, 직관적인 예시에 가깝다고 보면 된다.

**TAU**(Temporally Activated Unit)는 $H$에 속한 temporal index $i$에서 layer $j$의 모든 채널의 activation을 모은 벡터다.

$$
\text{TAU} = \big[\, A_{j,1}[i],\ \dots,\ A_{j,c}[i] \,\big]^\top, \qquad i \in H
$$

$c$는 layer $j$의 채널 수다. 따라서 TAU의 차원은 layer $j$의 채널 수와 같다. 처음 읽을 때는 "TAU의 수가 채널 수와 같다"고 적었는데, 수가 아니라 차원이다.

위의 예에서 채널 3을 보면 $H_{j,3} = \{0, 3\}$이므로 TAU는 두 개다.

$$
\text{TAU}_{j,3} = \Big\{ \big[\, a_{j,1}[0],\ a_{j,2}[0],\ a_{j,3}[0] \,\big]^\top,\ \big[\, a_{j,1}[3],\ a_{j,2}[3],\ a_{j,3}[3] \,\big]^\top \Big\}
$$

Threshold를 넘은 것은 채널 3의 노드지만, TAU에는 같은 temporal index에 있는 채널 1과 채널 2의 activation도 들어간다. 즉 어떤 temporal index에서 한 채널이라도 threshold를 넘으면, 그 위치의 정보가 중요할 수 있다고 보고 그 위치의 모든 채널을 벡터로 묶어 함께 본다. 위 예에서는 index 0, 1, 2, 3이 이렇게 선택되고 index 4는 어느 채널에서도 선택되지 않는다.

왜 벡터로 묶는가? 보통 채널 하나는 단순한 개념을 처리하고, 여러 채널의 개념이 모여 복잡한 개념을 이룬다. 이 논문도 한 temporal index에서 여러 채널이 함께 만드는 반응을 중요하게 본 것이라고 이해했다.

### 3. PTAP은 어떻게 뽑는가

$\text{TAP\_set}_j$는 layer $j$에서 모든 데이터에 대해 찾은 TAP을 채널 구분 없이 모은 집합이다. Layer별로 만드는 이유는 layer마다 receptive field의 길이가 다르기 때문이다. PTAP은 이 집합에서 고른 prototype들이다.

여기서 생긴 질문은 이것이다. $\text{TAP\_set}_j$에는 여러 채널에서 온 TAP이 섞여 있다. PTAP을 뽑으려면 비슷한 TAP끼리 구별할 수 있어야 하는데, 같은 채널에서 나온 TAP을 비슷한 것으로 보는 것인가?

정리한 답은, 채널로 나누는 것이 아니라 prototype을 먼저 뽑고 그것을 기준으로 그룹을 나눈다는 것이다.

1. Layer의 $\text{TAP\_set}$ 전체가 이루는 분포를 생각한다. 봉우리가 여러 개 있는 분포일 것이다.
2. MMD로 이 분포를 대표하는 prototype을 고른다. 세 개를 고른다면 봉우리마다 하나씩 뽑히는 식이다.
3. 뽑힌 prototype을 각 그룹의 대표로 둔다.
4. 나머지 샘플은 어느 그룹에 속하는지 알 수 없으므로, 모든 prototype과의 유사도를 계산해 가장 가까운 prototype의 그룹에 넣는다. 이것을 모든 샘플에 대해 한다.

## 이 논문이 새로 보여 주는 것

읽고 나서 스스로에게 던진 질문 세 가지다.

**Receptive field가 layer에 따라 달라지는 것은 당연하지 않은가.** CNN에서 layer가 깊어질수록 receptive field가 넓어지고 얕은 layer에서 좁은 것은 당연하다. 그렇다면 이 논문이 새로 보여 주는 것은 무엇인가. Receptive field의 크기를 안다고 해서, 채널이 의사결정을 위해 그 안의 어디를 중요하게 보는지까지 알 수 있는 것은 아니다. 이 논문은 채널별 activation으로 TAP을 구해 시각화하고, PTAP으로 그 패턴의 분포를 설명하는 핵심 샘플을 제시한다. "넓게 본다"가 아니라 "이런 모양을 본다"를 보여 주는 것이다.

**이미지 CNN의 초기 layer와 무엇이 다른가.** 이미지 CNN의 초기 layer는 배경이나 물체의 위치처럼 단순한 것을 본다. 시계열 CNN의 초기 layer는 어떨까. Receptive field가 좁으면 그 안에 들어오는 데이터 포인트가 적고, 포인트가 적으면 패턴도 단순하다. 시계열에서는 포인트가 많아질수록 복잡한 패턴이 된다. 그러니 시계열에서도 초기 layer는 단순하지만 특징적인 것을 본다고 보는 편이 맞다고 생각했다. 실험에서 초기 layer가 급격한 변화 같은 국소 패턴을 잡는다는 결과와도 맞는다.

**같은 temporal index에 있는 서로 다른 채널의 TAP은 다른가.** 같은 layer의 같은 temporal index라면 receptive field가 같으므로 TAP도 같다. 그렇다면 채널별로 threshold를 두는 것은 "어느 위치를 볼 것인가"를 정하는 일이고, 그 위치에서 여러 채널이 함께 만드는 반응(TAU)을 가지고 prototype을 판별하겠다는 것으로 정리했다.

## 한계와 더 생각해 볼 점

- 실험이 분류 task에 한정되어 있다. 더 복잡한 다변량 데이터로 확장할 수 있는지.
- CNN보다 복잡한 모델로 확장할 수 있는지.
- Gram kernel 기반 MMD 선택의 계산 비용. 실시간으로 쓸 수 있는지.
- Forecasting 모델에도 쓸 수 있는지.

## 남았던 질문과 답

공부할 당시에는 풀지 못하고 남겨 둔 질문들이다. 글을 정리하면서 답을 찾아 덧붙였다. 두 답 모두 저자들이 공개한 튜토리얼 코드(OpenXAIProject/PTAP)를 읽고 확인한 것이다.

**Q. Receptive field를 찾아가는 과정을 convolution 연산을 거꾸로 따라가는 것으로 이해해도 되는가? 2D convolution을 사용해 찾아가는 방식인가?**

거꾸로 따라가는 것은 맞지만, convolution 연산을 다시 수행하는 것이 아니라 index만 계산한다. Kernel 크기 $k$, stride $s$, padding $p$인 layer에서 출력의 $i$번째 노드는 입력의 $[\,i s - p,\ i s - p + k - 1\,]$ 구간을 본다. 따라서 어떤 layer의 구간 $[a, b]$는 한 layer 아래에서 다음 구간이 된다.

$$
[\,a,\ b\,] \;\longrightarrow\; [\,a s - p,\ \ b s - p + k - 1\,]
$$

이것을 convolution과 pooling마다 반복해 입력까지 내려가면 receptive field가 나온다. 예를 들어 $k=3, s=1, p=1$인 convolution 뒤에 $k=2, s=2, p=0$인 pooling이 있으면, pooling의 3번 노드는 convolution 출력의 $[6, 7]$을 보고, 그것은 입력의 $[5, 8]$이다. 가중치나 activation 값은 필요 없고 구조만으로 정해지므로, 같은 layer의 같은 temporal index는 채널이나 데이터와 무관하게 같은 receptive field를 가진다. 튜토리얼 코드는 구간이 입력의 범위를 벗어나는 가장자리 노드를 TAP에서 뺀다. "2D convolution"은 receptive field를 찾는 도구가 아니라 모델의 구현 방식이다. 튜토리얼 코드는 시계열을 높이가 1인 이미지로 놓고 2D convolution layer를 쓰는데, 이것은 사실상 시간 축 방향의 1D convolution이다.

**Q. 여러 채널의 activation을 벡터로 묶은 뒤, prototype 선택에서 그것을 어떻게 쓰는가?**

TAU는 TAP 사이의 유사도를 정하는 feature로 쓰인다. 튜토리얼 코드는 각 TAP에 대해 그 temporal index에서의 전체 채널 activation 벡터 $\mathbf{z}$(TAU)를 L2 정규화하고, 두 TAP의 kernel 값을 내적의 거듭제곱으로 둔다.

$$
k(a, b) = \big( \hat{\mathbf{z}}_a^{\top} \hat{\mathbf{z}}_b \big)^{p}
$$

이 Gram 행렬을 가지고 MMD-critic의 목적 함수를 greedy하게 키우는 TAP을 하나씩 고른다. $n$은 TAP의 수, $S$는 고른 prototype의 집합이다.

$$
J(S) = \frac{2}{n |S|} \sum_{i=1}^{n} \sum_{j \in S} k(x_i, x_j) - \frac{1}{|S|^2} \sum_{i, j \in S} k(x_i, x_j)
$$

앞의 항은 prototype이 전체 TAP과 비슷할수록, 뒤의 항은 prototype끼리 서로 다를수록 커진다. 선택이 끝나면 나머지 TAP은 kernel 값이 가장 큰 prototype의 그룹에 들어간다. 즉 두 TAP이 비슷하다는 것은 입력 구간의 모양이 유클리드 거리로 가깝다는 뜻이 아니라, 그 위치에서 같은 채널들이 같은 비율로 반응했다는 뜻이다. 모양이 시간 방향으로 조금 밀려도 채널의 반응이 같으면 같은 그룹이 되므로 shift에 강인해진다. 튜토리얼 코드의 지수는 $p = 20$이다. 이때 cosine 유사도 0.99는 약 0.82로, 0.9는 약 0.12로 바뀌어, 채널 반응이 거의 같은 TAP만 비슷한 것으로 남는다. 본문에서 Gram_p라고 적은 power scaling이 이 거듭제곱으로 보인다.
